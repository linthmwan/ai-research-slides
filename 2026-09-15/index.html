LLaDA-Image

從 image-only visual prior 到統一 generation / editing 的 fully open training recipe

arXiv Technical Report2026-09-03 · 回溯 12 天
Chuyan Chen, Haoxing Chen, Kun Chen et al. · AGI Research Center, Inclusion AI

6B Diffusion Transformer · 220M generation samples · Base + 2–4 step Turbo

Source: cover p.1 · arXiv:2609.03796v1
TL;DR

真正的主張不是「換了更大的 DiT」，而是把 視覺先驗、文字對齊、reference editing、few-step serving 串成一條可檢查、可重做的訓練路徑。

作者報告：Qwen-Image-Bench 開源模型 EN 53.53、CN 53.38，並釋出 weights、code 與 recipe。
Source: Abstract p.1 · §1 p.7 · §5.1.1 p.17–19
PROBLEM

開放模型的難題，從來不是只追一個 image-quality score

  • 早期 training 常把 visual-prior learning 與 language alignment 綁死，最耗算力階段要 paired captions。
  • Caption 昂貴且有資訊損失：完整圖被縮小時，caption 中的細節可能已不在 training target。
  • Generation、reference editing 與低成本 inference 通常被拆成不同 checkpoints。
  • 可用的 open system 必須同時處理：複雜／雙語指令、寫實畫質、未修改內容保留與服務成本。
  • 作者的切法：先從 image 自己取得 self-conditioning，文字 alignment 延後；editing 另加 semantic + pixel evidence。
把「資料對齊問題」從模型容量問題裡拆出來，才是這份 report 的核心。
Source: §1 p.7 · §2.3 p.10 · §4.2 p.12–13
CONTRIBUTIONS

五個組件，組成一套 end-to-end recipe

  1. Image-only first：以 masked self-conditioning 預訓練 visual prior。
  2. RQA + Connector：把 frozen dLLM VLM 轉成 DiT 可用的 condition。
  3. Single-stream DiT：一個 backbone 同時做 text-to-image 與 editing。
  4. Progressive curriculum：先升 resolution，再切 supervision modality。
  5. TwinFlow：把 Base 蒸餾成 2–4 step Turbo。
Source: §1 p.7 · Fig.2 p.7 · §2–4 p.8–17
ARCHITECTURE

理解、生成、編輯不是三個模型，而是三條在同一 DiT 交會的訊號

Source: Fig.3 p.8 · §2 p.8–10
CONDITIONING

RQA 不是替換 VLM，而是從 frozen VLM 挖出更適合生成的 hidden states

qres = RQA(q0, c)
hvlm = VLM(concat(c, qres))
hcond = Connector(hvlm)
  • Learnable query tokens 在 prefill 前 cross-attend 到 multimodal input。
  • RQA 讓 frozen backbone 暴露 generation-centric context；shallow Transformer connector 再做 condition-space alignment。
  • Text-to-image 和 image-only training 共用這條 RQA–VLM–connector 路徑。
昂貴的 VLM 不必全文 fine-tune；adaptation 被壓到 RQA 與 connector。
Source: §2.1–2.2 p.9 · Eq.2–4 p.9
UNIFIED EDITING

Editing 的 reference 一半走語意，一半直接交出像素證據

Semantic path

  • Reference image → SigLIP-VQ → DiT-specific embedder + 2 Transformer layers。
  • 輸出 `h_ref` 與 text condition concat，告訴模型 reference 的高階內容。
  • Reference 不進 VLM，避免與 instruction 的共同語意路徑混淆。

Pixel path

  • Clean reference → FLUX.2 VAE latent。
  • 與 noised target latent concat，讓未修改區域有 native pixel evidence。
  • 作者將這條路徑歸因於 identity、structure、texture、background consistency 的強化。
這是可被驗證的架構假說：語意 token 解決「改什麼」，VAE latent 守住「別改什麼」。
Source: §2.3 p.10 · Eq.6–8 p.10
IMAGE-ONLY PRIOR

Image-only training 仍然有 condition，只是 condition 來自同一張圖的 masked visual evidence

  • 從 image crop 取 SigLIP-VQ tokens，再由 frozen VLM 建 condition。
  • Mask 掉一部分 image tokens，避免 model 把完整 reference 當 identity shortcut。
  • 對高解析資料採 native crop → 小幅 resize，不必把完整圖硬壓至 256²。
xt = (1-t)x + tz
LFM = E[||F(xt, t, hcond) - (z-x)||2]

只更新 DiT、RQA、connector；SigLIP-VQ 與 VLM 維持 frozen。

Source: §4.2 p.12–13 · Eq.9–10 p.13
MECHANISM

先在 same-crop 上學「從稀疏可見 patches 補出完整 visual structure」，再學 text-to-image。這避免把 caption–image mismatch 當作 generation 的先天噪音。

這項設計的收益目前主要是機制論述與 staged recipe；report 沒有提供完整 remove-X quantitative ablation table。
Source: §4.2 p.12–13 · §4.3 p.14
DATA

資料策略：real-data dominant，但 synthetic data 保留給 text rendering

  • 220M generation samples 的 98% 為 real images；超過 90% 是 image-only training。
  • PT/MT 只用 real images；paired SFT 仍維持 real-image share >70%。
  • 篩選條件：image >1024² pixels、ArtiMuse ≥60、DeQA ≥4.0；caption 另做 agreement filtering。
Source: §3.1–3.2 p.10–11 · Fig.4 p.11
CURRICULUM

把兩個 distribution shift 分開：resolution 先變，supervision 後變

StagePixel budgetConditionPurpose
PT256²image-onlyvisual prior
MT512² bucketsimage-onlyadapt spatial budget
SFT512² → 1024²image–textsemantic alignment + detail
Editing1024²T2I:I2I = 1:1retain generation while learning edits
  • MT 先在 familiar image-derived condition 下適應更高 pixel budget；再改成 paired text。
  • Aspect-ratio buckets 讓不同 shapes 近似同一 pixel budget，減少 rank-level memory peaks / stragglers。
Source: §4.3 p.14 · §4.4 p.15–16 · Tab.2 p.14
OPTIMIZATION

SFT 不均勻抽 timestep：把更多預算放到高噪聲的 early denoising

epsilon ~ N(0,1)
t = sigmoid(Pmean + Pstd epsilon)
P_mean = 0.8P_std = 0.8
  • 大 t 對應高 noise：結構尚未建立，早期誤差會向後傳播。
  • 作者用 logit-normal sampling 偏向高-noise regime，避免平均浪費在已接近收斂的低-noise states。
  • DiT 全層用 parameter-free RMSNorm；generation stages 使用 Muon optimizer。
Source: §2.3 p.10 · §4.4 p.15 · Eq.11 p.15
JOINT TRAINING

為什麼 editing stage 仍混入 T2I？這是 capability replay，不只是湊資料

  1. 只用 I2I 的風險：editing data 分布窄，可能 overfit edit objective、削弱 open-ended generation。
  2. 1:1 T2I:I2I：每一步都讓 text-to-image 對 broad semantics、visual quality、prompt alignment 施加 regularization。
  3. shared backbone：visual prior 與 instruction understanding 的增益可在 generation/editing 兩任務間 transfer。
統一 checkpoint 的關鍵不是「把任務塞一起」，而是用 replay 主動壓制 task interference。
Source: §4.4.2 p.16
DISTILLATION

TwinFlow：用 signed time 把 generator 與 fake-score estimator 放進同一 backbone

+t: generator

  • 從 noise 到 clean sample 的 generation path。
  • DMD head 在 inference 保留。
  • Turbo 的 deployment 目標是 2–4 sampling steps。

-t: fake-score

  • 同一 DiT 的另一個 output head。
  • 1:2 generator:fake-score update schedule。
  • Inference 時 discard，因此不新增 inference-time overhead。
positive time = generator role; negative time = fake-score role
Source: §4.5.1 p.16–17 · Tab.2 p.14
RESULT · PRIMARY BENCHMARK

在 Qwen-Image-Bench，LLaDA-Image 報告 EN 53.53 / CN 53.38 overall；相對次佳開源 Z-Image Turbo 分別 +1.87 / +0.67。

1,000 stratified prompts；覆蓋 quality、aesthetics、alignment、real-world fidelity、creative generation。作者排除 prompt enhancement / explicit reasoning / prompt rewriting。

MECHANISM · THE CROWN PAGE

這份 recipe 最有價值的地方，是把變因順序固定：先 image-only prior → 再 resolution adaptation → 再 paired alignment → 最後 joint task + distillation。

它不是證明每個 component 的因果最優；它提供的是一條工程上可審計的 co-design path，並把應該被 ablate 的環節清楚地暴露出來。
Source: §1 p.7 · §4.2–4.5 p.12–17
EVIDENCE AUDIT

該信什麼、不該信什麼，分清楚

較有力的 evidence

  • 完整 PDF 直接列出 data ratio、training stages、hyperparameters、benchmark protocol。
  • Qwen-Image-Bench、text rendering、editing、legacy diagnostics 有拆項分數。
  • 公開 weights / code / recipe 使後續復現有落點。

不能替它補上的 evidence

  • arXiv technical report，非 peer-reviewed acceptance。
  • 沒有公開 reviewer record。
  • 沒有完整 component-removal ablation，無法從本報告證明每一 recipe choice 的獨立因果。
  • 多數 baseline 為作者彙整的 raw reported scores。

LIMITS

作者自己留下的三個缺口，比 headline score 更能決定下一輪工作

  1. Knowledge grounding：specialized subjects、culturally specific concepts 與 factual-context-dependent prompts 的 coverage 不夠。
  2. Typography：文字變長、region 變多、layout 變複雜時，rendering 會不穩。
  3. Resolution：只訓練到 nominal 1024² budget；native 2K 尚未被當成 evaluated capability。
工程上最值得補的是：以 ablation 驗證 staged curriculum，再針對 long/multi-region text 與 native 2K 擴展。
Source: §6 p.23
