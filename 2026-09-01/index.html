RASA: Disentangled Spatial-Motional Priors for Cross-Identity Character Animation

Zhen Xiao, Zhen Shen, Zhaofan Qiu, Ting Yao, Xueliang Liu, Tao Mei · Hefei University of Technology / HiDream.ai
ECCV 2026 acceptedarXiv:2608.28219v1Character animation

把跨身份角色動畫拆成 2D spatial calibration 與 3D motion semantic guidance 兩條訊號，不再讓比例對齊和動作控制互相污染。

Source: arXiv:2608.28219v1 · Abstract p.1; Fig.1 p.2
TL;DR

RASA 的重點不是又加一個 pose condition，而是把 幾何錯位 放在 denoising 起點修、把 關節/視角一致性 放在 DiT 中層修。

Spatial mapping ≠ motion control；兩件事拆開，cross-identity animation 才穩。
Source: Abstract p.1; Introduction p.2-3; Method p.5-8
Problem · pose-reference misalignment

跨身份動畫的錯，不只是不會跟 pose

  • Reference character 與 driving subject 常有 scale、global position、skeletal proportions 的差異。
  • Paper 把它稱為 pose-reference misalignment：pose 本身可能對，但套到另一個身份後幾何不相容。
  • 錯位如果在生成早期累積，後面再 feature fusion 會把 structural calibration 與 appearance rendering 纏在一起。
先把「骨架比例/位置」對齊，才談得上穩定 motion transfer。
Source: Introduction p.2
Why prior fixes are insufficient

preprocess / augmentation / late fusion 都碰到同一個限制

常見補法

  • explicit pose retargeting
  • pose augmentation
  • late-stage feature fusion
  • learnable similarity transforms

RASA 的批評

  • preprocessing 可能丟 motion detail
  • deep fusion 會把 alignment 和 rendering 混在一起
  • 2D pose 有 projection ambiguity，複雜動作缺 depth cue
Source: Introduction p.2-3; Related Work p.4
Core contribution

RASA = dual injection inside a DiT video backbone

  1. SPC: Spatial Prior Calibrator，在 denoising onset 持續加 2D structural prior。
  2. IMG: Inherent Motional Guider，用 shape-agnostic SMPL articulation 給 3D motion semantic。
  3. CIM-Bench: 656 manually filtered videos，專門測 realistic cross-identity discrepancies。
貢獻的密度在「拆訊號與注入位置」，不是單純多塞條件。
Source: Introduction p.3; §3.2 p.5-6; §3.5 p.9
Base model

底座：Flow Matching + Diffusion Transformer

zt = (1 - t)z0 + tz1
train vθ(zt, t, c) to predict (z1 - z0)
  • Video x 先由 VAE encode 成 z0；z1 是 Gaussian noise。
  • DiT 將 spatio-temporal latent 切成 patches/tokens，經 Transformer blocks + 2D RoPE 建模。
  • RASA 的 SPC/IMG 都是注入到這條 latent evolution 裡。
Source: §3.1 p.4-5; Eq.1-2 p.4-5

Reference identity conditioning

reference image 不是普通條件，而是被當成額外 frame

  • Reference image Ir 經 VAE 得 zr，concatenate 到 noisy video latents zt 的 temporal dimension。
  • 對 zr 加 significant positional encoding offset。
  • 目的：self-attention 能全域讀 identity / texture，但仍區分 static identity 與 dynamic latent flow。
identity 可以被全序列看到，但不跟時間演化混成同一種 token。
Source: §3.2 p.5-6

先故意把 driving pose 弄歪，再學會對齊 reference

training perturbation T

  • stochastic scaling
  • translation

learned target

Pdalign = R(P̃d, Pr)
  • 把 perturbed driving pose 投到 reference-consistent structural space。
Source: §3.3 p.6-7; Eq.4 p.7
SPC · frame-wise spatial cross-attention

driving pose 查 reference pose，校正每一 frame 的 2D 結構

ẑd,t = zd,t + Attention(RoPE(Qt), RoPE(K), V)
  • Qt: frame t 的 driving latent tokens。
  • K,V: shared reference latent，提供 reference geometry constraint。
  • 2D RoPE 保留 spatial topology；aligned features 在每個 denoising step 起點 element-wise add 回 noisy latent。
Source: §3.3 p.7; Eq.5 p.7
IMG · shape-agnostic motion

3D motion cue 要去掉「這個人的骨架比例」

  • ScoreHMR 從 driving video 估 3D human mesh parameters。
  • IMG 明確丟掉 subject-specific shape β，只保留 articulation θ。
  • motion prior m ∈ T x 263，含 root-relative joint rotations、velocities、foot contact signals。
這讓 motion signal 盡量只描述「怎麼動」，而不是「誰的身體怎麼長」。
Source: §3.4 p.8
IMG · where to inject

3D semantic 不碰初始 layout，進 DiT blocks 2-15

L = 14 projection layersblocks 2-15z3Dm ∈ T x D
  • Motion encoder Em 把 m 投影成 latent sequence z3Dm。
  • 作者把 3D motion dynamics 視為 high-level semantic，類比 audio-driven generation 的 phonetic features。
  • SPC 管 generative onset 的 coarse 2D geometry；IMG 管 intermediate latent evolution 的 depth-aware refinement。
Source: §3.4 p.8
Benchmark design

CIM-Bench 專測「真跨身份」而不是同人 pose 擾動

  • 用 text-to-image diffusion 生成 stylized character identities，另收集 real human portraits。
  • 不同角色執行同一 motion sequence，再抽 pose 作 driving motion。
  • 最終 656 high-quality character videos + pose sequences，手動過濾 DWPose 失敗樣本。
Source: §3.5 p.9; §4.1 p.9-10

訓練規格：1.3B backbone，小改動驗證要看 efficiency

Mechanism crown

Ablation 的訊息很清楚：SPC 是 2D 對齊門票，IMG 是 temporal / view consistency 的加速器。

IMG-only 最差，代表 3D semantic 不能跳過 spatial grounding；SPC+IMG full model 才把 TikTok FVD 289.16 降到 190.82，FID-VID 6.56 降到 3.32。

Source: §4.3 p.13; Tab.3 p.13
Ablation · attention direction

SPC 的 query/key 方向不是任意選

  • 正向：temporally evolving driving latent 作 query，reference latent 作 key/value。
  • 反向：static reference latent 作 query，會削弱 motion dynamics。
  • 作者解釋：動態 query 才能 retrieve / broadcast aligned identity features，同時保留 complex motion patterns。
Source: Fig.6 p.14; §4.3 p.14

Failure boundary

邊界很明確：RASA 還是假設 1:1 body-part correspondence

  • multi-headed、multi-armed、limb-less 等 non-humanoid topology 無法建立 reliable spatial correspondence。
  • Full-body animation 為主；手部和臉部仍只靠 pose representation。
  • SMPL 不顯式建 facial expressions / hand articulations，作者建議後續加入 SMPL-X / MANO。
Source: §6 p.15; Fig.7 p.15
Engineering read

對圖像/影片生成工程的啟發

  1. Conditioning 要按語義與時間深度分層：layout prior 放早，semantic motion 放中層。
  2. 不要把所有 control signal 都塞進同一個 adapter；會讓 calibration、rendering、motion refinement 互相干擾。
  3. Benchmark 要讓 failure mode 真實出現：CIM-Bench 比 synthetic affine perturbation 更能打到跨身份結構錯位。
  4. Ablation 要檢查「訊號方向」：FCA query/key 對調會改變 motion dynamics，這種細節很容易被忽略。
Source: synthesized from §3.2-3.5 p.5-9; §4.3 p.12-14

Appendix · key quote 2

“we explicitly discard the subject-specific shape parameters (β) and construct the motion prior solely from the articulation parameters (θ).”

中文：IMG 明確丟掉 subject-specific shape，只保留 articulation，讓 motion cue 與角色身形解耦。§3.4 p.8

中文：SPC 管 2D 對齊，IMG 管 3D anatomical guidance；兩者互補，不是替代。§4.3 p.13
