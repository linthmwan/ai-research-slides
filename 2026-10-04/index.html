TL;DR

把三種任務壓進一個條件幀模型，再把高解析推論拆成「低解析生成 + 五步 refinement」。

關鍵不是單點技巧：可 cache 的 condition K/V + 穩定化 Flow-GRPO + C2F/BSA 系統組合共同決定效率與品質。

PROBLEM

長影片同時卡在 temporal error 與 attention cost

  • Video continuation 的誤差會隨時間累積，minutes-long coherence 特別難。
  • 解析度、FPS、時長一起上升時，token 數把 dense self-attention 推向 quadratic cost。

品質與成本不是兩個獨立的 optimization。

  • T2V / I2V / continuation 若各自建模，訓練和 serving 的介面會碎裂。
  • 單一 reward 容易誘發 reward hacking，例如視覺品質變好但 motion 變靜態。
§1 p.4 · §3.3.2 p.12 · §3.4 p.13
CONTRIBUTIONS

一個 backbone，三個互鎖的系統決策

  1. Unified condition-frame model：以 0 / 1 / 多張 clean condition frames 分別表示 T2V、I2V、continuation。
  2. Video Flow-GRPO：selective SDE timestep、loss reweighting、max-group-std、三個 reward。
  3. Efficient generation：480p/15fps 先生成，再以 LoRA refinement 升到 720p/30fps；BSA 進一步降 attention。
  4. Open release + evaluation：程式、權重與內部 / VBench 2.0 報告。

UNIFIED TASK INTERFACE

T2V / I2V / continuation 只差 condition frame 的數量

condition tokens 的 self-attention 不被 noisy tokens 影響；condition tokens 不參與 cross-attention。

§3.2 pp.7–8 · Fig.5 p.8
CACHEABLE CONDITION

Block-causal attention 讓 condition K/V 可以跨 denoising step 重用

X = [Xcond, Xnoisy]   |   Xnoisy = Attn(Qnoisy, [Kcond, Knoisy], [Vcond, Vnoisy])
  • T2V：0 condition frames；I2V：1；continuation：multiple。
  • condition timestep 設為 0，condition-frame loss 不計入；序列在 train/inference 都固定。
  • 因 condition update 不依賴 noisy state，K/V feature 可 cache，這是 long-video serving 的直接收益。
§3.2 pp.7–8 · Eqs.(1–2), p.7
POST-TRAINING PROBLEM

Video GRPO 的難點：reward 到底該歸因給哪個 denoising timestep？

  • 標準 SDE sampling 在所有 timestep 注入噪聲，最終 reward 被平均攤回去，credit assignment 模糊。
  • LongCat 讓同一 prompt 的 samples 共用 initial noise，只隨機挑一個 early critical timestep 做 SDE step。
  • 其他 timestep 改採 deterministic ODE sampling；目標是更精確、可解釋的 policy update。
把 stochasticity 集中，不是少做探索，而是讓 reward signal 有能對應的責任點。
§3.3.1 pp.8–10
FLOW-GRPO

多 reward 不是加總分數，而是讓品質訊號互相制衡

  • Rewards：Visual Quality、Motion Quality、Text-Video Alignment。
  • HPSv3-only 會產生 static tendency；加入 motion reward 是對 reward hacking 的反制。
§3.3.1 p.10 · §3.3.2 p.12 · Figs.6,9
STABILIZING FLOW-GRPO

兩個 reweighting 與一個 robust advantage normalization

lambdapolicy(t, Delta t) = sqrt(t / (Delta t(1-t)))
  • 消去 policy gradient 的 timestep / step-size shrinkage。
  • noise clipping threshold tau = 0.45。
A-hatk,t = (Rk - mean(Rk)) / sigmamax,k
  • 用跨 groups 的 maximum std，避免低 dispersion group 放大不可靠 reward-model error。
  • KL 也有對應 reweighting。
§3.3.1 pp.10–11 · Appendix A.1.2 pp.28–30
EFFICIENCY SPINE

Coarse-to-fine：先求大結構，再花少量步數補高頻細節

§3.4 pp.13–14 · Fig.10 p.14
COARSE-TO-FINE PIPELINE

480p/15fps base -> trilinear upsample -> 720p/30fps refinement LoRA

Refinement 從 upsampled latent 加入 moderate noise；報告設定 tthresh = 0.5，使用 5 sampling steps。

§3.4.1 pp.13–15 · Fig.11 p.15
REFINEMENT OBJECTIVE

Refinement 學的是「upscaled low-res distribution -> high-res distribution」

xthresh = (1 - tthresh) xup + tthresh epsilon   |   vt' = (x0 - xthresh) / tthresh
  • xup 來自先 Decode、Upsample、再 Encode 的低解析結果。
  • LoRA 重用 base model 的生成知識，但改學 refinement path；與其他訓練 stage 解耦。
  • 條件任務在 refinement 前，把 high-res condition frames 與 upsampled generated frames 接在一起。
§3.4.1 pp.13–15 · Eqs.(11–18)
BLOCK SPARSE ATTENTION

不是固定 sparse pattern：先對 3D blocks 打分，再保留 top-r key blocks

  1. 將 query 與所有 key latents 分成不重疊的 temporal x height x width blocks。
  2. 以 query block 與每個 key block 的平均值算 similarity，選 top-r。
  3. 只在選中的 keys 內做正常 attention；報告稱保留少於 dense 計算的 10%。
  4. 實作還包括 ring block sparse attention，支援 context parallelism。
這份 report 的速度數字只能歸因給 distillation + C2F + BSA 的組合，不能把 12.3x 說成 BSA-only。
§3.4.2 pp.15–16 · Table 2 p.13
TRAINING STACK

讓 LoRA 成為 post-training 與 serving optimization 的可堆疊介面

  • Progressive pretraining：256p images -> 256p T2V -> joint T2I/T2V/I2V/VC -> 480p/720p。
  • SFT 使用多種 quality filter，並以 caption embedding density 做逆比例採樣維持類別平衡。
  • RLHF 是 T2V-only：group 4、64 prompts/step、16 sampling steps、SDE range [0,6]。
  • Refinement expert 先以 full attention 收斂，再開 93.75% sparse BSA；資料偏向 rich texture。

MECHANISM · CROWN PAGE

效率不是把 attention 隨便砍掉，而是把「哪些 state 可以固定、哪些 token 必須互看」先定義清楚。

  • condition K/V 不受 noisy denoising state 影響 -> 可 reuse。
  • C2F 讓 base stage 做 global structure，refinement 專注於 detail。
  • BSA 以 data-dependent block similarity 篩選 interaction，而不是盲目固定窗口。
  • 多 reward 加上 robust normalization，避免訓練只追一個容易被 hack 的分數。
§3.2 p.8 · §3.3 pp.10–13 · §3.4 pp.13–16
WHAT TO REUSE

對影像 / video 工程實作，最可遷移的不是 13.6B 本身

  1. 先檢查 condition branch 是否真的 state-invariant；若是，cache interface 能直接改變 serving cost。
  2. 對 flow/diffusion RL，先做 gradient scaling 與 credit-assignment audit，再比較 reward model。
  3. 把 C2F 的 low-res output 視為 distribution-shifted condition，而不是單純 upscale image。
  4. 稀疏 attention 要報 pattern、訓練策略、品質對照與 combined-vs-isolated ablation；只有 end-to-end speedup 不夠。
§3.2 p.8 · §3.3 pp.10–13 · §3.4 pp.13–16
LIMITS

這份報告自己留下的缺口

  • RLHF 只在 T2V 訓練；針對 video continuation 的 quality-degradation reward 是 future work。
  • I2V 的 image alignment、motion、overall 沒有領先比較模型。
  • 內部 benchmark 與自訓 judge 讓一些排名難以脫離作者 protocol 解讀。
  • 作者下一步指向更好的 physical knowledge、multimodal memory，以及 LLM/MLLM knowledge integration。
§4.2 p.18 · §5.1 pp.19–21 · §6 p.25
APPENDIX · HIGHLIGHTS

四句原文，對應四個真正的設計槓桿

The condition sequence remains fixed throughout both training and inference.

固定條件序列，是任務統一與 K/V cache 能同時成立的計算前提。§3.2 p.7

This approach enables precise credit assignment and leads to more stable, interpretable policy optimization.

只保留一個 stochastic timestep，讓 reward 的責任能落回特定步。§3.3.1 p.10

the mutual constraints imposed by multiple rewards create a natural regularization effect
