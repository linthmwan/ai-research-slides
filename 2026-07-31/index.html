Rethinking Output Alignment For 1-bit Post-Training Quantization of Large Language Models

Hoang Anh Dung, Cuong Pham, Cuong Nguyen, Trung Le, Thanh-Toan Do, Jianfei Cai
ICLR 2026 · OpenReview forumarXiv:2512.21651v3 · 15 May 20261-bit LLM PTQ

主角不是「再把 weight 壓低一點」，而是拆開 naive output alignment 在 1-bit regime 為什麼會壞。

cover p.1; arXiv abstract; OpenReview forum abgW71sKIt
TL;DR

1-bit PTQ 的真正敵人不是只剩一個 bit；是「target 漂移」加上「token geometry 被 MSE 扭歪」。

這篇用 true-target reconstruction 修 upstream error，再用 AMP mask 只放行不破壞 attention geometry 的 closed-form update。

Abstract p.1-2; §3 p.4; §4 p.5-6
Problem framing

為什麼 1-bit PTQ 不能只沿用「輸出對齊」直覺

  • Weight-driven：最小化 ||W - W_hat||，穩定但不直接保模型行為。
  • Output-driven：最小化 ||X_hat W - X_hat W_hat||，看似更 principled。
  • 在 1-bit regime，naive output-driven 反而會大幅退化，因為每層都在追逐已經被上游量化污染的 pseudo target。
  • 作者把 failure mode 明確拆成 error accumulation 與 anisotropic representation distortion。
Intro p.2-3
Prior work gap

前人的修法多在「補償誤差」；這篇回到 quantization stage 本身

Moderate precision PTQ
  • AWQ / SmoothQuant / GPTQ / QuaRot 等能在 4-bit 或 8-bit 保住性能。
  • 但 extreme binarization 不是 outlier smoothing 就能處理。
1-bit PTQ
  • BiLLM / PB-LLM / ARB 系列已經做 grouping、refinement、residual-aware update。
  • ARB-X 用 output alignment，但這篇指出 output objective 自身在 1-bit 下有錯配。
所以貢獻點不是「第一個 output alignment」，而是把 output alignment 改到不被 target drift 和 geometry distortion 反噬。
Related Works p.3
Contributions

四個可以落地檢查的主張

  1. 診斷 naive output-driven 1-bit PTQ 的兩個根因：layer-wise/global mismatch 與 representation geometry distortion。
  2. 把 reconstruction target 從 X_hat W 改成 full-precision XW，顯式補上 inherited error。
  3. 提出 Attention Matrix Preservation：用 token Gram geometry regularizer 過濾 closed-form update。
  4. 在 OPT / LLaMA / Qwen families 上驗證 perplexity、zero-shot QA、ablation 與 overhead。
contributions p.3; §5 p.7-10

Method 1 · Error-aware reconstruction

把 pseudo target 改成 full-precision true target

Old: LOA = ||X_hat W - X_hat W_hat||F2
New: L = ||XW - X_hat W_hat||F2 = ||X_hat(W-W_hat) + (X-X_hat)W||F2
  • (X-X_hat)W 是上游量化已留下的 inherited error。
  • 這讓 layer-wise objective 不再只對 quantized activation stream 自洽。
  • 代價是 loss landscape 更複雜，因此後面仍要保持 analytic / closed-form update。
§4.1 Eq.(2)(3) p.5
Method 2 · Token geometry

保 output 值還不夠，要保 token relation

Gq = (X_hat W_hat)(X_hat W_hat)T, Gf = (XW)(XW)T
LReg = -Tr(GqTGf)
  • Gram matrix 的每個 entry 是 token pair 的 similarity。
  • MSE 會偏向 high-magnitude activation components，低 variance 但結構重要的方向被低估。
  • 因此 regularizer 的目的，是讓 quantized output 的 relational structure 對齊 full precision。
§3.2 p.4; §4.2 Eq.(4)(5) p.5
Method 3 · 1-bit parameterization

仍保留 analytic-update PTQ 的工程形狀

W_hat = diag(alphar) B diag(alphac), B in {-1,+1}d_in x d_out
  • alpha_c 有 closed-form solution。
  • B 因二值限制，用 row-wise optimal sign update。
  • alpha_r 用 least-squares solution，實作中採 torch.linalg.lstsq 避免 pseudoinverse 不穩。
方法不是 training-heavy；它仍然是 calibration-set 上的一次性 PTQ。
§4.3 Eq.(7)-(10) p.6
Method 4 · AMP

AMP 是「更新方向過濾器」，不是推論時新增模組

MAMP = 1[ G ⊙ Delta <= 0 ]
  • 先用 reconstruction objective L 得到候選 closed-form update。
  • 再看這個 update 是否沿著 geometry regularizer L_Reg 的下降方向。
  • 不一致的元素直接 mask 掉，避免為了降低 output MSE 而增加 token geometry distortion。
§4.4 Eq.(12)-(14) p.6
Why it should work

AMP 把「局部重建更好」改成「局部重建不能破壞 attention geometry」。

Proposition 1 給出非增加 L_Reg 的方向性保證；真正的說服力還是後面的 ablation。

Limits

這篇的邊界要畫清楚，不然會被過度解讀

  • Scope: 1-bit weight-only PTQ；activation 保 full precision。
  • Not higher-bit: 作者明說 2/4/8-bit 常不全有 analytic solution，通常靠 heuristic rounding 或 gradient optimization，超出本文範圍。
  • One-time cost: 量化時間比 ARB-RC 高，雖然推論和儲存不加成本。
  • Exception: Qwen2-1.5B WikiText2 上 ours 92.34，比 ARB-RC 89.59 差。
Intro p.3; Tab.3 p.8; Tab.5 p.10; §6 p.9

What to reproduce first

最小可復現路線

  1. 先重現 ARB-RC baseline 的 block size 128、128 C4 calibration samples、15 iterations。
  2. 只替換 reconstruction objective 成 true-target 版本，量化 LLaMA-2-7B 與 OPT-1.3B。
  3. 再加入 AMP mask，優先驗 Tab.4(a) 的 LLaMA-2-7B C4 / WikiText2。
  4. 最後再跑 Qwen，因為 Qwen2-1.5B 有 corpus mismatch 例外，不能拿它當第一個 smoke test。

失敗根因原文

Appendix · Highlight 2

為什麼 MSE 會壞

minimizing mean squared error (MSE) in Euclidean space prioritizes high-magnitude activation components while underweighting low-variance but structurally important directions.

MSE 會偏向高幅度 activation，忽略低變異但結構重要的方向；token geometry 被扭歪，不是輸出值平均小一點就能補回。§3.2 p.4

AMP 的一句話定義

This leads to a directional filtering mechanism, where updates are accepted only if they are aligned with the descent direction of the regularizer.

AMP 的本質是方向過濾：只有不增加 geometry regularizer 的候選更新會被接受。§4.4 p.6

結論

這篇最值得帶走的是診斷框架：在極低 bit PTQ 裡，output alignment 要同時對齊 true target 與 token geometry。
