ELSA：突破 LLM 剪枝的「稀疏牆」

The Unseen Frontier: Pushing the Limits of LLM Sparsity with Surrogate-Free ADMM
Kwanhee Lee, Hyeondo Jang, Dongyeop Lee, Dan Alistarh, Namhoon Lee · POSTECH / ISTA
ICLR 2026arXiv 2510.01650v2 · 2026-02-23

Venue：PDF 每頁頁首「Published as a conference paper at ICLR 2026」· 程式碼 github.com/log-postech/elsa · 選題：今日 arXiv API 429，改以 web 搜尋兜底，挑 ICLR 2026 accepted 的剪枝論文 · Reviewer 資料：未抓取

TL;DR

剪枝方法卡在 50–60% 稀疏度，問題出在「逐層重建誤差」這個代理目標。ELSA 改用 ADMM 直接最佳化真正的語言模型 loss，在 LLaMA-2-7B 90% 稀疏下，C4 perplexity 比過去最好的方法低 7.8×；在 95% 稀疏度下，吞吐提升 3.98×、記憶體減少 7.80×。

Abstract, p.1
問題

「稀疏牆」：既有 LLM 剪枝到 70% 以上就崩

  • SparseGPT、Wanda、ALPS 等方法在 70% 以上 perplexity 暴增一個數量級（§2）
  • 對照：CNN 時代的剪枝常能做到 90% 以上（Lottery Ticket、SNIP）
§1–2, p.1–2
根因

主流作法：逐層最小化重建誤差，再把各層疊起來

xi* = argmin ED ‖ x̄iT g(xi-1) − xiT g(xi-1) ‖² s.t. ‖xi‖0 ≤ ki
  • 每一層只負責重現 dense 模型在校準資料上的輸出（第 i 層）
  • 記憶體很省：一次只需載入一層，所以在單張 GPU 上就能跑
作者主張：稀疏牆不是 LLM 的本質限制，而是問題定義錯了。
§2, eq.(2)(3), p.3
根因

代理目標的三個陷阱

  1. 近似解的誤差會累積：稀疏線性回歸是 NP-hard，只能靠 saliency 啟發式求近似解，每層的小誤差往後層層放大
  2. 搜尋空間被綁死：強迫每層特徵對齊 dense 模型，但最佳的稀疏模型不一定長這樣；各層從不聯合最佳化，前面的層定了就不再修正
  3. 代理 ≠ 真目標：就算 (2) 完美求解到誤差為零，也不保證 (1) 的語言模型 loss 最佳，甚至可能 overfit 到校準資料
§2, p.3
方法 · 問題重述

回到真正的問題：在稀疏約束下直接最小化 next-token loss

minx f(x) s.t. ‖x‖0 ≤ k → minx,z f(x) + IS(z) s.t. x = z
  • f：整個模型的 cross-entropy（next-token prediction），不是逐層代理
  • 變數分離：x 負責學習，輔助變數 z 負責滿足稀疏；IS 是稀疏集合 S 的指示函數（屬於 S 為 0，否則為 ∞）
  • 用 augmented Lagrangian：L = f(x) + IS(z) + λ/2‖x − z + u‖² − λ/2‖u‖²
§3.1, eq.(1)(4)(6), p.3–4
方法 · ADMM 三步

每一輪交替：訓練、投影、對偶更新

步驟更新式實際做法
x-update (7)argmin f(x) + λ/2‖x − zt + ut‖²用 Adam 跑梯度步，loss 外加一個把 x 拉向稀疏 z 的 proximal 項
z-update (8)ΠS(xt+1 + ut)閉式解：把 d−k 個最小的元素歸零
u-update (9)ut+1 = ut + xt+1 − zt+1對偶變數做一步梯度上升，累積 x 與 z 的差距

超參數：每 32 個 step 做一次 ADMM 投影；λ 在 70–90% 稀疏度時從 0 以 cosine 排程升到目標值；資料 32,768 條 × 2048 tokens（Tab.4、B.2）。

§3.1 eq.(7)–(9), p.4；App. B.2, p.16–17
方法 · 關鍵改進

Objective-aware projection：依 Fisher 重要度、而非權重大小來剪

zt+1 = argminz∈S Σi F̂ii ( zi − (xit+1 + uit) )²
  • 理想做法是用 Hessian H 誘導的範數投影（類似 Optimal Brain Surgeon）
  • 取對角近似 + 經驗 Fisher F̂，投影仍可逐座標分離 → 剪掉 F̂ii·wi² 最小者
  • F̂ 直接取自 Adam 的二階動差估計，不需額外計算
§3.2, eq.(10)(11), p.4–5

方法 · 擴展到大模型

ELSA-L：ADMM 狀態以低精度儲存

Q(z) = (zq, s), s = max|z| / vmax, zq = round(z / s); R(zq, s) = s · zq
  • z、u 是兩份和模型同大小的額外狀態；儲存時量化，計算前再反量化回高精度
  • FP8 相較 FP32 省 4×；每個 tensor 只多存一個 32-bit scale
  • 27B 實驗：x-update 用 adam8bit，(u, z) 存成 (bf16, fp8) → 狀態記憶體比 ELSA 少 55%，在 4×H200 上執行
§3.3 eq.(12)(13), p.5；§5.4, p.8；App. B.4, p.17
理論

收斂保證：收斂到 λ-stationary point

  • 假設：f 在 S 上有下界、β-smooth、μ-weakly convex
  • Corollary 4.5（ELSA）：若 β²/λ − (λ − μ)/2 < 0，任何極限點都是 (1) 的 λ-stationary point——無法再用步長 1/λ 的 projected GD 改進
  • Theorem 4.6（ELSA-L）：在 iterates 有界的前提下，量化帶來的不精確度 γ 只要滿足類似不等式，結論同樣成立（證明見 App. A）

這是非凸問題的局部穩定性保證，不是全域最優保證。

§4, p.5–6；App. A, p.13–15
實驗設定

7 個 baseline × 7 個模型（125M → 27B）

  • Baselines：Magnitude、SparseGPT、Wanda、ALPS、L-ADMM、SAFE、SparseLLM
  • 模型：OPT-125M/1.3B、Gemma-2-2B/27B、LLaMA-3.2-3B、LLaMA-2-7B/13B（另加 LLaMA-3-8B）
  • 評估：C4 / WikiText2 perplexity；lm-eval 的 7 個 zero-shot 任務
  • ⚠ 資料量不對等：baseline 依慣例用 128 條 C4 校準序列，ELSA 用 32,768 條（作者的理由是 ELSA 屬於迭代最佳化）

消融 · 目標函數

NTP 會隨資料量持續變好，REM 則提早飽和

  • 資料少時 REM（重建誤差）較好
  • 資料增加時 REM 收益遞減，NTP（next-token）持續大幅改善
  • REM 必須儲存 dense 模型的預測，資料量一大，記憶體開銷就很可觀

局限

讀這篇要注意的幾點

  • 中低稀疏度未必最佳：LLaMA-2-7B 在 50% 時 ELSA 為 7.5 / 9.81，比 SAFE（6.72 / 8.87）和 SparseGPT（7.01 / 9.23）差（Tab.10）
  • 資料與算力不對等：baseline 用 128 條校準序列，ELSA 用 32,768 條、4 張 GPU；雖然有比較同資料量的 Wanda + 再訓練，但沒有提供同資料量的 ALPS
  • 記憶體需求接近整模訓練：作者主張可用 offloading 彌補，但沒有量化實驗
  • 加速依賴特定 kernel：只在 RTX 3090、batch-1 decode 上測量；沒有測 prefill 或大 batch serving
  • 數字小出入：內文 p.7 寫 LLaMA-2-13B 在 90% 時的 perplexity 是 27.84，但 Table 10 是 30.19 / 25.07
Tab.10 p.20；§5.3 p.8；§6 p.9
解讀

為什麼這個方法 work（編者解讀，非論文結論）

  • 本質上是「帶稀疏投影的持續訓練」：x 在真實 loss 上學，z 只負責投影，u 記住被剪掉的方向，讓模型逐步適應 mask
  • Fisher 投影讓 mask 選擇跟著 loss 曲率走；稀疏度越高，選錯一個權重的代價越大，所以收益在 90% 時最明顯
  • 對圖像 / 多模態工程師：若部署瓶頸在 decode 頻寬，非結構化 90% 稀疏 + SpMV kernel 是量化之外值得一試的方向；但要先確認推論引擎支援 sparse kernel

Objective-aware projection 為什麼幾乎不用額外成本

We found that using Diag(H) allows us to retain this simplicity while still keeping the benefits by zeroing the entries with the smallest contribution to the objective rather than by their magnitudes.

我們發現，使用 H 的對角近似可以保留逐座標投影的簡單性，同時依「對目標函數的貢獻」而非權重大小來決定歸零哪些元素。§3.2, p.4

the standard Adam optimizer has already made F̂ available for free via its second-moment estimates
