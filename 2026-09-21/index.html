GVPO++: Group Variance Policy Optimization for
LLM Post-Training and On-Policy Distillation

用「群組中心化 reward matching」消掉 partition function：不靠 importance sampling，同時主張唯一 KL-constrained optimum。

Kaichen Zhang · Yuzhong Hong · Junwei Bao · Hongfei Jiang · Yang Song · Dingqian Hong · Hui Xiong
NeurIPS 2025 GVPO · extended manuscriptarXiv v1 · 2026-09-18
Source: arXiv:2609.21432v1 · Abstract p.1 · deck date 2026-09-21
TL;DR

GVPO++ 把「學 reward」改成
對齊群組內相對 reward 的距離。

零和 group weights 同時消掉 Z(x)、避免 IS ratio，並把 OPD 推到 sequence level。
Abstract pp.1–2; §IV pp.4–6; §V pp.7–8
01 · PROBLEM

GRPO 很省，但 off-policy ratio 是它的薄弱點

  • GRPO 以 group reward 標準化代替 value model，降低 LLM RL 的記憶體與計算成本。
  • 若重用 off-policy samples，importance ratio `pi_theta / pi_s` 可非常大或非常小，gradient 會不穩。
  • clip ratio 可以止血，但會引入 bias；paper 想要的是連 ratio 都不必算。
§I p.1; §IV-C/E pp.5–6
02 · DESIGN CONSTRAINT

難點不只 stability：KL optimum 裡還藏著 Z(x)

pi* = pi_ref * exp(R / beta) / Z(x)
  • closed-form optimum 很漂亮，但 `Z(x)` 要對所有 possible responses 做 expectation，實作上不可行。
  • DPO 用 pairwise comparison 讓 Z(x) 相消；GVPO 改用 group zero-sum weights。
  • 目標：保住 KL-constrained target，同時讓 sample source 不再綁定 current policy。
§III p.3; §IV-A p.4
03 · CORE CONSTRUCTION

先把 reward 與 implicit reward 都「去平均」

wi = (Ri - R_bar) - beta[(log(pi_theta/pi_ref))i - mean(log(pi_theta/pi_ref))]
  • 每個 prompt sample k 個 responses，計算 actual rewards。
  • response weight = centered actual reward - centered implicit reward。
  • sum wi = 0：共享的 `beta log Z(x)` 在 group update 中直接抵消。
Eq.6–7; §IV-A/B p.4

Figure 1：同一個 GVPO loss 有三個有用的讀法

不是疊三個 tricks；是「中心化」一個設計，同時帶出三種性質。
Fig.1 p.2; §IV-B/E pp.4–6
04 · MSE INTERPRETATION

學的是「相對排序的距離」，不是 absolute reward

L_GVPO = 1/2 * sum [(implicit_Ri-mean) - (actual_Ri-mean)]2
  • 相同 group shift 不改 loss；高 actual reward 的 response 會被推向更高 implicit reward。
  • centered form 避開了 absolute reward 中無法計算的 partition term。
  • 這給的是 loss-gradient equivalence；paper 的 optimality theorem 仍另有 sampling condition。
§IV-B pp.4–5; Theorems IV.1–IV.2 pp.4–5
05 · WHAT THE THEOREM CLAIMS

在 stated support condition 下，
GVPO 的 population objective 有唯一 minimizer，且它就是 KL-constrained optimum。

Theorem IV.2 把 sample policy 從 pi_ref 放寬到「support 包含 pi_ref」的任意 pi_s。
Theorems IV.1–IV.2, pp.4–5
05 · SAMPLING DECOUPLING

不再把 sample source 與 policy update 綁死

  • 傳統 off-policy：重用 stale sample 時要乘 `pi_theta/pi_s`。
  • ratio explosion / vanishing 讓 optimization 脆弱；clipping 取穩定卻犧牲無偏性。
  • GVPO：可從 historical / mixed / expert samples 取樣。
  • 只需 stated support condition；因此為 experience replay 打開路徑。
核心不是「off-policy 比較快」而已，而是改變了可用資料的集合。
§IV-C/E pp.5–6
06 · REGULARIZATION VIEW

GVPO 的穩定性不是額外加 penalty，而是從推導長出來

三個項

  • Group-relative advantage：偏好高 reward responses。
  • Cov(log pi_theta, log pi_ref)：限制 policy drift。
  • Var(log pi_theta)：控制 distribution shape。

直覺

  • Cov 在 pi_ref = pi_old 時對應 trust-region-like control。
  • Var 不強迫全 uniform 或 one-hot；可把壞 response 機率壓成 0。
  • paper 對比 entropy：它的 strength 可能很敏感。
Eq.10; §IV-E pp.5–6
06 · POSITIONING

DPO、GRPO、GVPO：相消的是同一個麻煩，但方式不同

DPOPairwise Bradley-Terry cancellationPreference pairs; paper notes possible multiple minima
GRPOGroup relative advantages + IS for off-policyNo value model; IS can destabilize
GVPOGroup-centered zero-sum cancellationUnique optimum claim + flexible pi_s
§IV-D/E pp.5–6; Table I p.9
07 · ON-POLICY DISTILLATION

把 teacher/student 的 sequence log-ratio 直接塞進 GVPO

L_GVPD = 1/2 * sum [log(pi_student/pi_teacher) - mean(log(pi_student/pi_teacher))]2
  • 令 reward = log(pi_teacher / pi_ref) 後，pi_ref 在最後 objective 裡消掉。
  • paper 主張 teacher pi_t 是 exact optimum；不必用 token-level alignment。
  • 因此可 distill 不同 tokenizer / vocabulary 的 model families。
Eq.12–16; §V-A p.7

08 · FAILURE MODE

標準 OPD 的 length bias：越長，累積 log-ratio 越不利

f(x,y) = 1 / |y|alpha
  • 長 sequence 的 cumulative log-ratio 可持續下降，形成越訓練越短的 feedback loop。
  • length normalization 對抗這個 bias；它只是 extended OPD 的一個 example。
  • alpha 仍需 tune，且效果不保證單調。
§V-C p.8; Fig.3 p.8; §VII-B p.11
09 · POST-TRAINING PROTOCOL

主實驗把 algorithm 當唯一變因

  • Base: Qwen2.5-Math-7B
  • Train: Competition Math
  • Eval: AIME2024, AMC, MATH500, Minerva, OlympiadBench
  • AIME uses avg@32; others pass@1
  • Same settings across baselines
  • k = 5 responses / prompt
  • 1024 prompts per step; minibatch 256
  • 8 x 80GB H800; about 12h per 7B experiment
§VI-A p.9

MECHANISM · THE CROWN PAGE

真正的槓桿是 center the group：
它同時移除 Z(x)、移除 IS ratio、並生成穩定正則項。

所以 ablation 不是「少兩個 bonus term」：它拆掉的是讓 objective 可運作的結構。
§IV-B/E pp.4–6; Table II p.10
13 · LIMITS

哪些結論要保留條件？

  • 唯一 optimum 是 population-objective theorem，並依賴 sampling-support condition；實際 finite-sample optimization 仍是另一件事。
  • 主結果集中在 math reasoning；Llama、Reasoning Gym 擴大範圍，但跨更多 production tasks 的外推仍未展示。
  • extended OPD 的 alpha 不單調；作者自己也把 `f(x,y)` 視為可設計、需要調整的 objective family。
  • 無公開 reviewer JSON；不補寫不存在的 reviewer consensus。
Theorems IV.1–IV.2 pp.4–5; §VI–VII pp.9–11
