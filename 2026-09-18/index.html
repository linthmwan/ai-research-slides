CAGE

Curvature-Aware Gradient Estimation

讓 low-bit QAT 的更新，真的朝量化格點收斂

Soroush Tabesh · Mher Safaryan · Andrei Panferov · Alexandra Volkova · Dan Alistarh
MLSys 2026 OralarXiv v3 · 2026-06-18
Source: CAGE paper cover p.1 · official MLSys 2026 paper index
TL;DR

不要只穿透量化梯度；也要把參數拉回量化支撐集。

CAGE 以 residual e = x - Q(x) 補正 STE/AdamW，在幾乎不改成本的前提下縮小 low-bit accuracy gap。

Source: Abstract p.1; §3.1–3.3 pp.3–6
01 · PROBLEM

QAT 的瓶頸不是只有不可微

  • 量化算子 Q 的 gradient 幾乎處處為 0；STE 以 identity 近似它。
  • STE 很實用，但已知會有收斂慢與不穩定的問題。
  • 既有改良多是 learnable scales 或 gradient tricks，欠缺統一的最佳化目標與 guarantee。
真正要解的是：模型怎樣同時降低 task loss，又靠近可部署的量化格點？
Source: §1 pp.1–2; §3.1 p.3
02 · BASELINE

STE 忽略了量化殘差的幾何

STE: grad_x f(Q(x)) ~= grad f(Q(x))
  • 對 SGD，STE 可視為 error-feedback：量化殘差會在下一步回灌。
  • 這只在 Hessian 是 isotropic quadratic 時會「剛好正確」。
  • 一般 loss landscape 裡，不同方向的曲率不同；同一個 residual 不該一視同仁。
Source: §3.1 p.3
03 · REFRAME

把 QAT 變成雙目標 Pareto 問題

Objective A

  • 降低 task loss
  • 尋找 stationary direction

Objective B

  • 降低 x 與 Q(x) 的距離
  • 滿足量化約束
Pareto stationarity: grad f(x) + lambda (x - Q(x)) = 0
在量化下，不能硬要求一個完美 stationary quantized point；平衡才是可達的定義。
Source: Eq.2, §3.1 p.3
MECHANISM · 皇冠頁

CAGE 的核心不是「多一個 regularizer」，而是讓 optimizer update 直接遵守 Pareto direction。

量化 residual 成為明確更新項；藉由既有 Adam statistics 或 decoupled post-step，避免顯式 Hessian 的成本。

Source: §3.1 pp.3–4; §3.3 pp.5–6
04 · TWO FORMS

Coupled 與 decoupled：方向相同，縮放位置不同

Coupled

  • 先將 lambda e_t 加進 gradient
  • Adam state 會預條件化 residual
  • second moment 提供 diagonal curvature proxy

Decoupled

  • 先完成 base optimizer update
  • 再施加 lambda e_t
  • 避免 variance estimate 扭曲校正量
SGD 下兩者等價；有 state 的 optimizer 下，作者主要使用 decoupled CAGE-AdamW。
Source: §3.1 p.4; §3.3 p.5
05 · UPDATE

CAGE-AdamW 是一個輕量後處理

e_t = x_t - Q(x_t) | x_(t+1) = x_tilde_(t+1) - alpha lambda_t e_t
  1. 以量化 forward pass 取得 STE gradient，AdamW 正常更新。
  2. 以 no-grad 計算 instantaneous residual。
  3. 在 update 後加上 residual correction，推向 quantized support。
不需要儲存新 persistent state；介面只要求 quantizer 能回傳或重算 Q(x)。
Source: Algorithm 1 pp.5–6; §4 p.7
06 · SCHEDULE

先沉默，後線性 ramp

lambda_t = 0 before sT; then ramp linearly to lambda
  • 早期會快速跨越 quantization cells：residual 接近 mean-zero perturbation，強拉反而加噪。
  • 接近收斂時，Q(x_t) 穩定，residual 變 coherent，才有累積校正效果。
  • 實驗建議：silence ratio s = 0.8–0.95；lambda = 1–10（依 model）。
Source: §3.3 p.6
07 · QUANTIZER

強 baseline 是 QuEST；CAGE 不綁 QuEST

  • 實驗基礎：row-wise Hadamard rotation、symmetric quantization、trust-masked STE。
  • CAGE 只使用 e_t = x_t - Q(x_t)，因此可附著於不同 bit-width 和 quantizer。
  • 論文的主張是 optimizer correction，不是另造一個 low-bit GEMM kernel。

訓練採 simulated quantization/dequantization + standard-precision matmul。

Source: §4 pp.6–7
08 · THEORY

收斂對象換成 Pareto gradient

E ||grad_P f(Q(x_hat))||^2 = O(1 / sqrt(T))
  • Theorem 1 假設 smooth loss、unbiased bounded-variance stochastic gradient，及 smooth surrogate quantizer。
  • SGD setting 下對 Pareto-optimal state 有 ergodic convergence。
  • 作者強調 bound 不含由量化 error 造成的 non-vanishing term。
理論保證精確覆蓋 SGD；AdamW 版本是同一方向的實務設計與實驗驗證。
Source: Theorem 1, §3.2 p.5
09 · SYNTHETIC

非 isotropic quadratic：先檢驗「曲率」這個前提

  • 4-bit quantized quadratic，condition number 取 1、10、100。
  • 比較 STE-SGD、STE-Adam、CAGE-Adam；每組以 10 seeds 測 final validation loss。
  • CAGE 在不同 condition number 都降低 stationary error，trajectory 也更接近 true optimum。
Source: §4.1 p.7; Fig.1–2 p.7
10 · FINETUNE

MXFP4 Llama-3.2-3B：accuracy gap 約減半

  • Llama-3.2-3B 在 Tulu-SFT fine-tune；FP32 master weights，forward weights/activations 皆為 MXFP4。
  • 評測 GSM8K exact-match、HellaSwag accuracy、WinoGrande accuracy。
  • Figure 3 顯示 CAGE 對 SOTA MXFP4 QuEST baseline 三項皆提升；作者總結 quantization error 約減半。
Source: §4.2 p.7; Fig.3 p.8
11 · PRETRAIN

從 30M 到 800M、W2A2 到 W4A4

  • Llama-style model sizes：30M / 50M / 100M / 200M / 430M / 800M。
  • C4，固定 D = 100 x N tokens；每個 pretraining result 平均 3 seeds。
  • 比較 CAGE+QuEST、QuEST 和 BF16 reference；硬體為 8xH100。
Source: §4.3 pp.7–9

13 · SCALING

有效 capacity：低位元不只看單點 loss

  • 作者報告相對 prior SOTA：4-bit 的 parameter efficiency 增益超過 10%，2-bit 超過 20%。
  • 4-bit 在擬合結果最好，但 CAGE 下 3-bit 的相對劣勢已很小。
Source: §4.3 p.9; Fig.6 p.8
14 · DEPLOYMENT

關鍵結果：W3A3 CAGE 超過 W4A4 QuEST 的 Pareto front

  • Figure 5 的 loss-vs-model-size 比較涵蓋 W2A2/W3A3/W4A4。
  • 作者描述 CAGE 在每個 precision 都 Pareto-superior to QuEST。
  • 特別地，W3A3 CAGE 被報告為 Pareto-superior to W4A4 QuEST。
如果這個趨勢能遷移到實際 kernel，改善 QAT 可能比單純多給一個 bit 更有價值。
Source: §4.3 p.9; Fig.5 p.8

17 · UNIVERSALITY

不是只對 AdamW 有效

  • 另以 50M OLMo2-family models + ClimbMix 測 AdamW、Muon、Shampoo、SOAP。
  • 每個 optimizer 都先各自 tune hyperparameters，再以相同 initialization/setup 比較有無 CAGE。
  • Figure 4 的實驗中，CAGE 對四種 optimizer 都降低 validation loss，使用 s=0.9、lambda=5。
Source: §4.3 p.9; Fig.4 p.8
18 · WHY LATE

Figure 7：CAGE 的增益在訓練後段更明顯

  • 50M Llama、W4A4 的 baseline 隨訓練繼續有 quantization error 增加。
  • CAGE correction 開始後，quantization error 有明顯下降，且 final loss 更低。
  • 這和「早期 residual 抵消、晚期 residual coherent」的 schedule 解釋對齊。
Source: §3.3 p.6; §4.3 pp.9–10; Fig.7 p.10
ENGINEERING INTERPRETATION

將 QAT 視為「能否達到 Pareto stationarity」，比把 STE 當固定近似器更可操作。

它把 quantizer 的 residual 變成 optimizer 可用的訊號；而不是只在 forward pass 接受量化誤差。

Source: §3.1–3.3 pp.3–6
19 · LIMITS

該相信到哪裡

  • 理論是 SGD + smooth-surrogate assumptions；它不是對 AdamW 實作的完整同構證明。
  • 訓練採 simulated Q/DQ，不是端到端 custom low-bit kernel benchmark。
  • W3A3/W2A2 當時缺少廣泛可用 hardware support，部署結論仍需系統層驗證。
  • LOTION baseline 是 reimplementation，作者也承諾未來重跑。
Source: §3.2 p.5; §4 pp.6–10
20 · PRACTICAL

若要把 CAGE 放進既有 QAT recipe

  1. 保留既有 quantizer、STE 和 optimizer；每 step 拿到 e = x - Q(x)。
  2. 先用 silence + ramp，避免早期把 high-frequency quantization noise 當方向。
  3. 從 decoupled AdamW 開始測，追蹤 loss、quantization error、wall-clock、memory。
  4. 要區分 algorithm gain 與 real low-bit kernel gain：兩者都需要量。
Source: Algorithm 1 pp.5–6; §3.3 p.6; §4 p.10
