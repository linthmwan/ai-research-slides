TROLL: Trust Regions Improve Reinforcement Learning for Large Language Models

把 PPO-style clipping 換成 token-level KL trust-region projection：更穩的 RLVR 訓練，沒有推論額外負擔。

Philipp Becker · Niklas Freymuth · Serge Thilges · Fabian Otto · Gerhard Neumann
Karlsruhe Institute of Technology · Microsoft Research
ICLR 2026arXiv:2510.03817v3
Source: TROLL paper, cover p.1 and Fig.1 p.2 · 2026-10-19
TL;DR

TROLL 把「ratio 截斷」改成
可微的 token-level KL 投影。

它不改 reward、也不換 advantage estimator；只替換 PPO-like objective 裡最粗糙的穩定化步驟。

論文主張：在 math / code RLVR、不同模型與 optimizer 變體上，同時改善收斂速度、穩定性與最終 success rate。
Abstract p.1; Introduction pp.1–2
THE FAILURE MODE

PPO clipping 是 trust region 的便宜近似，但不是 trust region 本身

  • 目標：新 policy 不要偏離收集 rollout 的舊 policy 太遠，importance ratio 才不會失控。
  • PPO 作法：把 ratio 限在固定範圍；超界 token 的梯度會被壓掉。
  • 代價：clip 是啟發式，會造成 poorly calibrated update、對 implementation / hyperparameter 敏感。
  • 缺口：GRPO、Dr.GRPO、GSPO 等改善 advantage estimation，卻大多仍沿用 clipping。
PPO: min(r * A, clip(r, 1 - eps, 1 + eps) * A)
§1 pp.1–2; §2 p.3; Eq.2 p.4
CONTRIBUTIONS

這篇不是另一套 RL algorithm，而是可替換的 policy-update layer

  1. Exact constraint：對每一個 token distribution 施加 KL trust region。
  2. Differentiable：用 implicit differentiation 穿過投影，不切斷 constrained token 的學習訊號。
  3. Sparse：只保留高概率 logits，讓 vocabulary-scale projection 可實作。
  4. Drop-in：可搭 PPO、GRPO、Dr.GRPO、GSPO、RF++；實驗跨 math / code 與多個模型家族。
§3.1–3.2 pp.4–6; §4 pp.6–7
CORE MECHANISM

投影的是「新 token distribution」，不是直接 clip 一個 scalar ratio

Inputs

  • pi_old：產生 rollout 的 policy。
  • pi_tilde：目前參數下的 token distribution。
  • 若兩者 KL 已在範圍內，保持 pi_tilde。

Output

  • pi：在 KL ball 內、又最接近 pi_tilde 的可行 distribution。
  • 後續 policy ratio 用 pi；另以 regression 讓 pi_tilde 向 pi 對齊。
  • 因此限制真正施加在 discrete policy space。
Fig.2 p.4; §3.1 pp.4–5
PIPELINE

TROLL training loop：rollout buffer → sparse logits → KL projection → RL update

對每個 response token：僅當 KL constraint 被違反時才解 projection；否則原 distribution 直接通過。

Figure 2 p.4; Algorithm 1 p.6
THE PROJECTION

一個 convex problem，解成新舊 policy logits 的幾何插值

pi = argmin KL(pi || pi_tilde) subject to KL(pi || pi_old) <= eps
pi = normalize(exp((eta * log(pi_old) + log(pi_tilde)) / (eta + 1)))
  • eta 是由一維 convex dual 求出的步長：它決定把目前 policy 拉回 old policy 多遠。
  • 投影只對少數違反 bound、但重要的 tokens 啟動。
  • 此式提供 exact token-wise feasibility，不是對 surrogate ratio 做硬截斷。
Eq.3 p.4; Eq.4 and §3.1 p.5
KEEP IT DIFFERENTIABLE

兩條訊號各司其職：可行 projected policy 做 RL，未投影 policy 被拉回可行集

Policy-gradient branch

  • 用 projected pi / pi_old 計算 policy-ratio term。
  • 新 policy 更新仍由 advantage signal 驅動。

Regression branch

  • KL(pi_tilde || stopgrad(pi)) 讓模型本身接近 projection。
  • 梯度不回推到 pi，避免「把 projection 拉向模型」而失去 constraint。
  • 作者所有實驗設 alpha = 1。
關鍵不是每次都投影，而是把「受限的解」變成可學習的 target。
Eq.5 and §3.1 p.5
SYSTEMS ENABLER

真正的障礙是 vocabulary：完整 token distribution 太大

  • Qwen3 tokenizer 的例子有 151,936 logits / token；逐 token 儲存與投影不可接受。
  • TROLL 選 cumulative mass 至少 1 - delta 的高概率 tokens，並一定保留 sampled token。
  • 對 discarded tokens 保留小 default mass，再重新 normalize；top-K 同時是 high-entropy case 的記憶體上限。
keep top-K tokens until cumulative probability >= 1 - delta
§3.2 pp.5–6
SPARSITY RESULT

K=64、delta=10^-5：通常只留 5–10 個 token，就保住 99.999% mass

K = 645–10 tokens99.999% mass
  • 這使 projection 的 memory / compute 以稀疏 token subset 運作，而非完整 vocabulary。
  • 論文也給 sparse KL approximation 的 error bound；在其 Qwen3 hyperparameters 下，作者稱誤差約比 bound 小兩個數量級。
  • 成本相對於模型越大越不顯著，因 vocabulary 尺寸在同一模型家族中固定。
§3.2 p.6; §6 p.10
EXPERIMENT DESIGN

不是只在單一 Qwen setting 贏：測的是 objective 可移植性

Tasks & data

  • DAPO-Math：17k 題，保留 1,024 題 DAPO-Eval。
  • Math：MATH500、AMC、AIME、OMNI-MATH、OlympiadBench、Minerva。
  • Code：Eurus-Code；另有 GSM8K 與 Eurus-Math。

Models & optimizers

  • Qwen3 0.6B–14B、Qwen2.5-Instruct、Llama 3.1/3.2、SmolLM3、Apertus。
  • 對照 Clip vs TROLL，並換 GRPO、PPO、Dr.GRPO、GSPO、RF++。
  • 也檢查 BAPO 與 clipping-free GPG。

MECHANISM CROWN PAGE

為什麼會更穩？不是「約束更多」，而是給每個 token 一個可微的可行更新

Clip 把超界訊號截掉；
TROLL 把 distribution 拉回 KL-feasible region，再繼續學。

  • Projection fraction 與 Clip 影響的 token 比例大致相近，所以穩定性不是單純因為 restrain 了更多 token。
  • 投影後的 regression 讓 base model distribution 逐步接近可行解，避免 successive update 再次跑遠。
  • 作者觀察到 TROLL 較能保留 entropy；在 Eurus-Code 上，entropy preservation 與較佳表現相關。
§3.1 p.5; §6 pp.9–10
ABLATION

KL bound 與 top-K 不是無腦越大越好：projection 要夠準、但不必很密

  • epsilon 太小：學得慢，但 convergence 不一定變差。
  • epsilon 太大：更新過大，final success rate 變差。
  • K=16：稀疏近似太粗；K=256：成本變高但不優於 default K=64。
Figure 5 p.10; §6 p.9

LIMITS

目前證據強在 RLVR，但外推範圍要講清楚

  • 作者只評估 dense models，最大到 14B；MoE 與更大規模仍未驗。
  • 實驗主體是 math reasoning 與 code generation 的 RLVR，並沒有完整覆蓋一般 RLHF / preference learning。
  • vision-language 等其他 modalities 的 logits / projection behavior 被作者列為 future work。
  • OpenReview reviewer JSON 在本次 ingest 時 HTTP 403，沒有把不存在的 reviewer score 補進來。
§7 p.10; ingest record
ENGINEERING TAKE

給 RL post-training 工程師的三個可操作判斷

  1. 若 Clip 是瓶頸：優先把 policy constraint 與 advantage estimator 解耦；TROLL 的價值在這個介面。
  2. 若 full-vocab KL 太貴：先量 token-mass concentration。方法的可行性依賴 sparse token distribution，而非魔法。
  3. 若把它上 production：把 epsilon、K、entropy、projection fraction、wall-clock 一起當成 monitored training signals。
這篇最有價值的不是「又一個 RL loss」，而是把 LLM token distribution 當成可被正確約束的 policy object。
§3.1–3.2 pp.4–6; §6 pp.9–10
APPENDIX · AUTHOR WORDS

原文螢光筆：把核心 claim 與檢驗點放回原句

We replace the clip objective with a novel discrete differentiable trust region projection, which provides principled token-level KL constraints.

以可微分的離散 trust-region projection 取代 clip objective，直接施加有原理的 token-level KL 約束。

using K=64 and delta=10−5 usually allows us to keep 99.999% of probability mass with only 5−10 average tokens.

K=64、delta=10^-5 時，通常只需平均 5–10 個 token 即可留下 99.999% 機率質量。

The observed stability improvements are thus not merely caused by more restrained tokens.

觀察到的穩定性改善，不只是因為約束了更多 token。
