Re2: Unlocking LLM Reasoning via Reinforcement Learning with Re-solving

將「重來」變成一個可學習、可估值的 RL action，而不是無止盡地把錯的 CoT 寫長。

Pinzheng Wang et al. · Soochow University · Huawei 2012 Labs · Tianjin University
ICLR 2026 · AcceptedarXiv 2603.07197 · 2026-03-07
Full paper title: Re2: Unlocking LLM Reasoning via Reinforcement Learning with Re-solving · cover / Abstract p.1
TL;DR

不是讓模型「想更久」，而是讓它在早期路徑已經壞掉時，知道何時放棄並重新解題。

Re2 把 restart 的價值設為「從頭解題的預期成功率」，從純 end-reward 走向可比較的三向決策。
Abstract p.1 · §4.2 p.6
PROBLEM

RLVR 的盲點：錯的 prefix 會把更多 token 變成沉沒成本

  • 同一題多次 sampling 時，CoT 長度與 accuracy 呈負相關；長 trace 常源於早期關鍵錯誤。
  • 錯誤 prefix 越長，從該 prefix 繼續的相對 accuracy drop 越大。
  • 標準 0/1 end reward 只獎勵「答對」；它沒有一個正面的 action 讓模型承認目前的 reasoning 不可靠。
真正要修的不是 token budget，而是 reasoning trajectory 的可逆性。
§3.1–3.2 p.4 · §4.2 p.6
EVIDENCE

更長的 CoT 並不自動帶來更高 accuracy

128 responses per problem；作者發現全資料集及不同難度單題都呈現長度與正確率的負相關。

Fig.3 · §3.1 p.4
EARLY ERROR

多數錯誤回答在前 20% 就已經難以救回

  • 把錯誤 response 截成 20%、40%、60%、80% 的 prefix，再要求模型繼續。
  • 與從頭解相比，prefix 越長，accuracy drop 越明顯。
  • 多數錯誤 trace 在僅用前 20% 時，已首次跨過顯著 drop 門檻。
§3.2 p.4 · Fig.4 p.5
PAPER CLAIM

四件事：先證明問題，再把 restart 接進 RL

  1. 分析早期 reasoning 品質與最終成功率的關係。
  2. 提出 Re2：允許輸出 final answer 或 re-solve。
  3. 用 out-of-group completions 估值 redo action。
  4. 在 matched token budget 下，跨 5 benchmarks / 5 model settings 比 DAPO 更好。
Abstract p.1 · §3–5 pp.3–10
METHOD / INTUITION

Re2 把一條單行 CoT，改成能退出再開局的決策過程

  • 標準 reasoning：即使 path 已偏離，也傾向繼續往下寫並硬給最終答案。
  • Re2：在中間 prefix 可選擇 resolve；下一輪從原問題重新開始，而非沿錯誤 prefix 修補。
  • 這是 policy 學到的行為，不是評測時外掛的固定 heuristic。
Fig.2 · §4 p.5 (diagram omitted: extracted image includes a cropped paper caption)
METHOD / PIPELINE

Prefix groups：把中途思考狀態變成可訓練的 decision point

每題先 sample n 個 full responses，隨機截在 [0, 0.8]；對每個 prefix 生 m 個 continuations。

§4.1 pp.5–6 · Fig.5 pp.5–6
METHOD / REWARD

三向 reward：讓「重做」有可比較的價值

r = 1 (correct) · 0 (incorrect) · r_redo = P_out(correct) x (1 - P_out(redo)R) / (1 - P_out(redo))
  • 對目前 prefix 的 final answer：沿用 RLVR 的 1 / 0 reward。
  • 對 redo：看其他 prefix group 的完成情況，估計「若重新開始」的成功機率。
  • out-of-group 設計避免當前 prefix 的估值回饋到自己；R 是可允許的最大 redo rounds。
Eq.1 · §4.2 p.6
METHOD / UPDATE

新的是 reward，不是再造一套 optimizer

Group-wise advantage

A_hat = (r - mean(r_group)) / std(r_group)
  • 同一 prefix group 內正規化 reward。
  • 所有 outcomes 相同的 group 會被 filter，因為 advantage = 0、沒有 gradient。

Policy update

  • 用 DAPO 的 clipped importance-ratio objective 更新 policy。
  • 因此 paper 的可歸因核心是「何時 restart」的 reward design，而不是 optimizer replacement。
§4.3 p.7 · Eq.2–3
EXPERIMENT / FAIRNESS

訓練與比較設定

Training

  • DAPO-Math-17K；答案轉為 integers，以可靠的 rule-based reward 判分。
  • Re2：batch 32、n=8 prefixes、m=8 continuations、8192 max seq、R=5。

Comparison

  • DAPO 用相同 generated-token budget 訓練。
  • 評測包含 AIME24/25、AMC23、GSM8K、GPQA-Diamond；模型從 3B 到 14B，含 base / instruct / reasoning。

TEST-TIME SCALING

超過 64 samples 後，Re2 繼續受益；DAPO 多數投票開始飽和

  • 作者以相同 sampled-output count 比較，無論 sample 是 final answer 或 redo attempt。
  • sample count 超過 64 後，Re2 一致超過 RLVR baseline，並隨 test-time compute 繼續改善。
  • 低 sample budget 時恰好相反：redo 佔掉輸出，valid final answer 比例下降，可能比 RLVR 更差。
Re2 不是免費提升；它把 compute 轉向「重新搜尋 trajectory」，需要足夠 sample budget 才能顯現優勢。

TRAINING DYNAMICS

模型先學會重做，再學會少重做

  • redo probability 在前 20 steps 急升，之後逐漸下降。
  • incorrect-answer probability 大幅下降；correct-final-answer probability 緩慢上升。

Re2 的核心不是「更會猜答案」，而是停止把錯誤推理硬湊成最終答案。

MECHANISM / WHERE IT HELPS

最大收益出現在「有能力但不穩定」的題目

  • Group 1：base model 完全不會，RL 無法憑空教會；Re2 多半選 resolve 而非輸出不可信 final answer。
  • Group 4：DAPO 偶爾能解，Re2 從 51.2% 提升到 81.7%；restart 增加走到成功 path 的機率。
  • 題目越容易，resolve probability 越低。
§5.5 p.10 · Fig.8 p.10
LIMITS

這篇沒有說的比它說的更重要

  • Small budget：redo 會減少 valid finals，低 sample count 可能輸給 RLVR。
  • Capability ceiling：base model 完全解不了的題，Re2 不會創造知識或技能。
  • Scope：訓練是 DAPO-Math-17K，四個 benchmark 屬數學推理；只有 GPQA-Diamond 作 out-of-domain science check。
  • 作者沒有獨立 limitations section；以上是正文直接報告的 empirical boundary。
§5.1 p.7 · §5.3 p.9 · §5.5 p.10
ENGINEERING TAKE

把 restart 當成 policy action，三個實作問題就變得明確

  1. State：要在哪些 partial traces 詢問「繼續或重做」？Re2 用隨機 prefix truncation。
  2. Value：restart 的 reward 不能只靠這條 trace；Re2 用 out-of-group empirical success。
  3. Budget：redo 消耗 rollout；測試時的 sample budget 是結果是否反超的重要條件。
  4. Boundary：這是 trajectory recovery，不是能力擴充。
§4.1–4.3 pp.5–7 · §5.3, §5.5 pp.9–10
APPENDIX / PRIMARY TEXT

作者最直接的問題定義

“when the initial direction or quality of the CoT is suboptimal, the model often fails to reach the correct answer, even after generating several times more tokens.”

當 CoT 起手方向或品質不佳，即使多產生好幾倍 token，模型仍常無法走到正確答案。

“The results reveal that for most incorrect responses, a significant drop in accuracy already occurs when only the first 20% of the response is used as the prefix.”

多數錯誤回答只取前 20% 當 prefix，就已出現顯著準確率下跌。

Abstract p.1 · §3.2 p.4
APPENDIX / PRIMARY TEXT

作者對機制的表述

“Re2 enables the model to output a final answer only when it is confident, and to honestly indicate the need to restart when the reasoning becomes unpromising.”

Re2 讓模型只在有把握時作答，推理不再有希望時則明確選擇重來。
