週三主題: Video generation / temporal models

Radial Attention:
O(n log n) Sparse Attention
for Long Video Generation

把 video diffusion 裡的 spatiotemporal energy decay 轉成 static sparse mask: 4x 長影片仍保品質, attention compute 降到 O(n log n).

Xingyang Li*, Muyang Li*, Tianle Cai, Haocheng Xi, Shuo Yang, Yujun Lin, Lvmin Zhang, Songlin Yang, Jinbo Hu, Kelly Peng, Maneesh Agrawala, Ion Stoica, Kurt Keutzer, Song Han
NeurIPS 2025 camera-readyarXiv:2506.19852v2MIT / NVIDIA / Princeton / UC Berkeley / Stanford
Source: cover p.1; changelog p.11; arXiv comment
TL;DR

Dense attention 不一定要全刪；真正該做的是讓 compute density 跟 attention energy 一起衰減。

Radial Attention 保留近距離 spatiotemporal relations, 對遠距 frame 逐層降密度；結果是 O(n log n) attention, 不是 O(n) 線性替換的品質折衷。

1.9x default speedup4.4x lower tuning cost3.7x long-video inference speedup
Abstract p.1-2; Fig.1 p.1; Tables 1-2 p.7-8
Problem

長影片的成本不是「多幾幀」而已，是 3D dense attention 的平方爆炸。

  • Video diffusion 比 image 多一個 temporal dimension；HunyuanVideo 5s 720p 影片約 110K latent tokens.
  • 3D dense attention 要算所有 token pair：time / memory 都是 O(n^2)，長影片或高解析度立刻變成瓶頸。
  • FlashAttention 降 memory overhead，但沒有改掉 quadratic time complexity。
Attention(Q,K,V) = softmax((QKT) / sqrt(d))V   =>   QKT costs O(n2)
Preliminary p.4 lines 275-293
Why prior sparse attention is not enough

SVG 能快，但它把「選 mask」變成 runtime 動態判斷；長影片訓練時反而卡住。

Dynamic / generic sparse

  • SVG: 對每個 head 動態選 spatial 或 temporal mask，inference 可加速。
  • 問題: unseen long-video distribution 可能 misclassify，且 dynamic profiling 不適合 training。
  • PowerAttention / linear attention: 複雜度漂亮，但忽略 video 的 spatial-temporal locality。

Radial Attention

  • 用同一個 static mask 同時支援 training + inference。
  • mask 不是任意 local window，而是從 attention score 的 distance decay 推出。
  • 保留 softmax attention，只 prune 低能量 relations，所以能接 pretrained model + LoRA。
Intro p.2; Related Work p.3; Fig.3 p.3
Core contributions

這篇最紮實的地方：它不是只報速度，而是把 sparse pattern 的來源、複雜度、誤差和 fine-tuning 一起補齊。

  1. Observation: post-softmax attention 隨 temporal/spatial distance 衰減，且 exponential fit 達 R2 > 0.985。
  2. Mask: central band full density；distance 每 double，compute density 約 half。
  3. Theory: long video frame count 增長時 attention complexity 變成 O(n log n)，並給 attention error bound。
  4. Adaptation: Radial + LoRA 擴長影片，避免 dense full fine-tuning 的巨大成本。
  5. Evidence: HunyuanVideo / Wan2.1 / Mochi 1 都做 default + long-video benchmark。

Mechanism

Radial 的直覺：近處保真、遠處保覆蓋；不是全局平均稀疏。

如果 attention energy 隨距離衰減，那 compute 也該以距離衰減。中央 band 保 full density，外圈 band 越遠越稀；這讓 mask 同時有 local fidelity 和 long-range coverage。

§4.2 p.5-6; Fig.5 p.6
Mask design

Temporal band 每遠一層，密度減半；spatial diagonal 同步縮窄。

  • Temporal density: 1 / 2floor(log2(max(|i-j|,1))).
  • Spatial diagonal width: floor(s / 2floor(log2(max(|i-j|,1)))); too narrow後改降 diagonal frequency。
  • Attention sink: every token can attend to first frame，保住全局 anchor。
§4.2 p.5-6 lines 443-604
Static vs dynamic

SVG 要先判斷 head 類型；Radial 直接用 unified static mask。

靜態 mask 是關鍵：同一套 pattern 可以用在 training，也可以直接接 LoRA 做 longer-video adaptation。
Fig.3 p.3; §4.2 relation to SVG p.6
Complexity

在固定每幀 token 數 s 時，frame count 長起來只剩 O(n log n)。

#kept <= 4s2f log2 f = 4s n (log2 n - log2 s)   =>   O(n log n)
  • Central band + attention sink: <= 4s2f entries。
  • 可見 diagonal 的 bands 對每層維持 bounded compute。
  • 當 diagonal width < 1，改成降低 diagonal frequency，避免遠距 frame 完全失聯。
  • Empirical headline: HunyuanVideo 509-frame 720p 時，attention compute 比 dense 少 9x。
§4.2 Eq.5-6 p.6; Appendix A.1 p.16-17; Fig.2 p.2
Long-video adaptation

Radial Attention 不是只做 inference trick；它讓長影片 fine-tuning 也便宜。

Why dense FT hurts

  • Pretrained model 原本只看 short videos；直接拉長會有 distribution mismatch。
  • Dense attention 在 long videos 上 fine-tune 成本太高。
  • Training-free RIFLEx 在 4x length 時品質明顯劣化。

Radial + LoRA

  • Radial 保留 softmax attention 的重要 relation，不大改 backbone。
  • LoRA 加在 Q/K/V/O projection，就能低成本適應長序列。
  • Style LoRA 可與 long-video Radial LoRA 合併。

Crown page: why it works

Radial 的勝點是「物理式 locality prior」剛好對上 video DiT 的 attention distribution。

Generic sparse attention 也能省 compute，但如果 sparse pattern 跟 pretrained attention 不對齊，fine-tuning 會先花力氣修 mismatch。Radial 直接用 observed decay 做 mask，所以 LoRA 能把容量留給 temporal coherence 和 fidelity。

Ablation / analysis

兩個機制證據：exponential fit 很強，Radial 的 attention error 也更低。

Decay fit

  • 用 y = exp(-a x + b) 擬合 attention decay curves。
  • Figure 8 regression: R2 > 0.985。
  • 這支持「距離越遠、compute density 越低」不是純 heuristic。

Attention MSE

  • Radial Attention: 3.9e-3
  • SVG: 4.4e-3
  • STA: 1.5e-2
  • Radial mask 更接近 dense attention output。
LoRA analysis: Radial+LoRA 隨影片長度增加可 match / outperform full FT，這是 deck 裡最值得帶走的工程訊號。

Limitations

這不是長影片 attention 的終局；resolution 方向還沒有真正解掉。

  • Decay assumption is simplified: natural videos 的 dependencies 比 exponential model 複雜。
  • Resolution scaling remains hard: paper 明說方法對 resolution s 仍有 quadratic complexity。
  • Implementation headroom: 現版用 FA2；STA with FA3 在某些 default-length raw speed 可能更高，FA3 upgrade 留作 future work。
  • No public reviews ingested: reviewer perspective 無法補 baseline fairness / claim strength 的外部爭點。
Limitations p.10 lines 1388-1393; §5.2 p.9 lines 1276-1281
Engineering takeaways

如果要落到 video generation stack，Radial Attention 的啟發有三個。

  1. 先量 attention distribution，再設 sparse pattern：不要把 LLM sparse attention 直接搬到 video。
  2. static mask 比 dynamic routing 更適合 training：尤其是要做 long-video LoRA 或 continuation tuning。
  3. 保留 softmax attention 的可遷移性：線性 attention 省算力，但 pretrained fidelity recovery 可能要 massive retraining。
  4. 長影片收益大於短影片：default length 只是 1.8-1.9x；4x length 才看到 3.7x inference / 4.4x tuning cost 的槓桿。
