TS-Attn: Temporal-wise Separable Attention for Multi-Event Video Generation

Hongyu Zhang*, Yufan Deng*, Zilin Pan, Peng-Tao Jiang, Bo Li, Qibin Hou, Zhiyang Dou, Zhen Dong, Daquan Zhou
ICLR 2026 Conference PaperarXiv 2604.19473Training-free attention controlPublished 2026-04-21

把多事件影片生成的問題，收斂成 cross-attention 的時間分離：每段 motion region 看自己的 event，不再互相搶注意力。

Source: paper p.1; Abstract pp.1-2; OpenReview forum QixNhagZ9t identified, reviews unavailable
TL;DR

TS-Attn 不是再訓練影片模型，而是在推論時重排 cross-attention。

在 motion-related tokens 上加入 event-aware bias，Wan2.1-14B / Wan2.2-A14B 的 StoryEval-Bench 平均分分別提升 33.5% / 16.4%，latency 只多約 2%。
Abstract p.2; Table 1 p.8; Table 3 p.9
Problem

Multi-event prompt 卡在兩個壞選項中

多段短 prompts

  • Action fidelity 較好，因為每段只描述單一事件。
  • 但 clip stitching 容易 content drift / temporal inconsistency。
  • 多次 inference 讓成本接近 81 x n frames。

單一複雜 prompt

  • Global coherence 較好，整段影片在同一 prompt 下生成。
  • 但模型常漏掉個別事件，或把事件順序 hallucinate。
  • 問題變成 prompt following 與 temporal alignment。
論文要解的不是單純畫質，而是「同一段影片裡每個事件該在什麼時間發生」。
§1 pp.2-3; §2 p.4
Failure analysis

根因在 cross-attention：event token 會搶錯 frame

  • 作者在 Wan2.2-A14B 的中層、20% denoising step 觀察 attention。
  • Motion-related region 沒有強烈對應當下 verb，例如 watch / dips / take it out 被錯配到背景或同區域。
  • 這會直接導致 event omission 與 temporal errors。
§3.1 pp.4-5; Fig.2 p.3
Core insight

每個 frame 的 motion region 應主要看「同時間」event。

不同 event 在 temporal dimension 上的 interaction 要被壓低，但不要用 hard mask 把全局 coherence 切壞。
§1 p.2; §3.1 p.5
Method overview

TS-Attn 只替換早期 denoising 的 cross-attention

  • 適用於 DiT / MM-DiT / Cross-DiT 類模型的 text cross-attention。
  • T2V 套在前 20% denoising steps；I2V 套在前 40%。
  • Temporal segmentation 可以由 GPT-4o-mini、user input 或 uniform split 提供。
§3.2 p.5; §4.1 pp.6-7; Fig.3 p.4
Module 1 · MRE

Motion Region Extraction：只改會動的 token

As = Mean(Is(QKT/√d))
Ms = FK(I(As ≥ Mean(As)))
  • 用 subject token 的 cross-attention map 近似 motion-related semantic layout。
  • 用 mean(As) 作自適應 threshold，再以 erosion kernel K=3 清理 noise。
  • Ms 是後續 EAM 的作用範圍，避免背景 attention 被亂改。
§3.3 pp.5-6
Why MRE matters

不限制 motion region，背景會被 modulation 打亂

這頁是工程重點：attention control 不是越大力越好，而是要限制在會動的空間區域。
§4.4 p.9; Fig.7 p.15
Module 2 · EAM

Event-aware Attention Modulation：在 logits 裡加可分離 bias

A = softmax((QKT + Ms ⊙ R(Q,K) ⊙ B(Q,K)) / √d)
  • B(Q,K)：attention rearrangement，讓 Qi 對應 event ei 加正 bias，其他 events 加負 bias。
  • R(Q,K)：attention reinforcement，依原本 attention sharpness 自適應調整強度。
  • Ms：motion mask，限制 modulation 只發生在 motion-related region。
§3.4 p.5
Attention rearrangement

時間段 Qi 只應強化自己的 event ei

b+i = max(QiKT) - mean(QiKT)
b-i = min(QiKT) - mean(QiKT)

對 ei 加 b+；對 ej, i != j 加 b-；prompt context 不加 bias。

  • 這是 TS-Attn 最關鍵的 temporal correspondence。
  • 不是把所有 event token 都變強，而是「該時間段只扶該事件」。
  • 各段 B(Qi,K) concatenate 成完整 B(Q,K)。
§3.4 p.6
Attention reinforcement

如果原 attention 太平，就加大重排強度

p'i = (pi - pmini) / (pmaxi - pmini + eps)
r+i = rmin + (1 - p'i)(rmax - rmin)
  • 若對齊 event 的 attention 本來很弱，正向 reinforcement 變大。
  • 若其他 event 的 attention 本來太強，負向 correction 也變大。
  • 論文設定 rmin=1, rmax=1.5。
§3.4 p.6
Extension

多 subject 場景：逐 subject 加總 bias，不重算 attention

A = softmax((QKT + Σi=1..m Msi ⊙ Rsi(Q,K) ⊙ Bsi(Q,K)) / √d)
  • 對 subject list [s1...sm] 逐一抽 motion mask 與 event-wise bias。
  • 只 sequentially index 需要的位置來構造 bias terms。
  • 作者稱多 subject overhead 接近單 subject。

Limits

限制：paper 沒有 formal limitations，但有三個工程邊界

  • 需要 event / subject parsing。 粗分段可行，但仍要知道 prompt 裡有哪些事件與 subject。
  • 依賴 cross-attention 架構。 方法展示在 CogVideoX / Wan 類 DiT cross-attention，不保證所有影片生成器無改動可套。
  • 評測仍偏 verifier-driven。 GPT-4o / LLaVA-OV + human 評估比單一 metric 好，但多事件影片品質仍難完全客觀量化。
  • 長影片只是延伸展示。 Wan 約 5 秒限制下，更多事件要接 LongCat-Video 等多 clip 系統。
§3.2 p.5; §4.1 pp.6-8; Appendix E pp.15-16; Appendix I p.17
Engineering read

如果要借這篇做產品化，優先看三件事

  1. Hook point: 早期 denoising cross-attention 是否能穩定攔截 Q/K logits。
  2. Parser: event list、subject list、temporal intervals 要能從 prompt 可靠抽出；精準度不用到 frame-level。
  3. Safety rail: modulation 必須有 motion mask，否則容易把背景也變成 control target。
這篇的價值在「低成本 attention surgery」：把訓練問題換成 inference-time routing 問題。
§3.2-3.4 pp.5-6; Fig.7 p.15; Table 8 p.20

Takeaway

多事件影片生成的控制點，可能不在更多訓練資料，而是在正確時間、正確 motion region 的 attention routing。
