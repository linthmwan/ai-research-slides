TS-Attn

Temporal-wise Separable Attention for Multi-Event Video Generation

不訓練、不重生影片；只在早期 cross-attention 把「這一幀該看哪個事件」重新排好。
ICLR 2026 PosterarXiv v1 · 2026-04-21
Hongyu Zhang et al. · Peking University Shenzhen Graduate School, Zhejiang University, Nankai University, MIT, Nanjing University, UC Santa Barbara

Full paper title: TS-Attn: Temporal-wise Separable Attention for Multi-Event Video Generation

Paper cover p.1 · arXiv:2604.19473 · OpenReview: QixNhagZ9t
TL;DR

讓 motion token 對準此刻對應的 event token；其餘事件仍留在全域 context，不用硬切掉。

Wan2.2-A14B：StoryEval-Bench average 48.3% → 56.2%，單張 A100 latency 846 s → 863 s。
Abstract pp.1–2 · Table 1 p.8 · Table 3 p.9
THE PROBLEM

Multi-event prompts force a bad trade-off

MULTI-PROMPT / CLIP-BY-CLIP

  • 每個短 prompt 的 action fidelity 較好。
  • 但重複生成、KV / noise stitching 帶來 drift、時間不連續和昂貴的延遲。

ONE GLOBAL COMPLEX PROMPT

  • 同一個 generation pass 保留全域 coherence。
  • 但 event omission 與 temporal hallucination 增加；模型不會在正確時段回應每個 action。
目標不是二選一：保留 single-pass coherence，同時讓 event-following 有時間感。
§1 pp.2–3 · §2 p.3
DIAGNOSIS

Vanilla cross-attention mixes events in the same frame

兩個根因：motion-event temporal misalignment，以及跨事件 verb 對同一 video region 的 attention coupling。
§3.1 p.4 · Figure 2 p.3
WHAT THE PAPER CONTRIBUTES

A small intervention with a clear causal story

  1. 先在 Wan2.2-A14B 的 early-denoising attention map 找出錯誤對齊。
  2. 以 motion-region mask 限制修改範圍，不碰無關背景 token。
  3. 依 temporal interval 對 matching event 加正 bias、other events 加負 bias。
  4. 以 attention sharpness 自適應調整介入強度；套件式接到多個 backbone。
§1 pp.2–3 · §3 pp.4–6
ARCHITECTURE

TS-Attn replaces early cross-attention, not the full model

Only early denoising cross-attention is changed: first 20% steps for T2V and first 40% for I2V.
§3.2 p.5 · §4.1 p.7 · Figure 3 p.4
INPUT TO THE MECHANISM

An event list becomes coarse temporal intervals

PROMPT

“A cat watches a fish, dips its paw, then takes it out.”

  • Events are parsed into [e1, e2, ..., em].
  • Video queries are segmented into [Q1, Q2, ..., Qm].

INTERVAL SOURCE

  • User input, uniform segmentation, or GPT-4o-mini planning.
  • The paper reports minimal final-performance differences among them.
  • So exact timestamp labels are not the core dependency.
It needs a time plan, but a rough plan is enough because routing is soft rather than a hard isolation mask.
§3.2 p.5 · Appendix E p.16
MODULE 1 · MRE

Find where the subject is moving before changing attention

As = mean(subject-token attention)   ;   Ms = erode(As >= mean(As), K=3)
  • Average attention over the subject’s text tokens to get a semantic layout.
  • Threshold at its own mean; erosion with K=3 removes scattered noise.
  • Use Ms to confine modulation to motion-related foreground tokens.
This is the guardrail: attention routing is not applied indiscriminately to the background.
§3.3 p.5 · Eqs.1–2
MODULE 2 · REARRANGEMENT

For interval Qi, reward ei and suppress other events

MATCHING EVENT

B(Qi, K) = b+i   if token belongs to ei
  • Positive bias is derived from max(QiKT) - mean(QiKT).
  • Creates a strong temporal correspondence for the motion token.

NONMATCHING EVENTS

B(Qi, K) = b-i   if token belongs to ej, j != i
  • Negative bias is min(QiKT) - mean(QiKT).
  • Remaining prompt context has zero bias.
§3.4 p.6 · Eqs.4–7
MODULE 2 · REINFORCEMENT

If the routing signal is flat, push harder — only as much as needed

r+i = rmin + (1 - p'i) x (rmax - rmin)   ;   rmin=1, rmax=1.5
  • Weak matching-event attention receives a larger positive strength.
  • Strong nonmatching-event attention receives a larger negative strength.
  • The factor R scales rearrangement B; it does not replace temporal routing.
Reinforcement is adaptive calibration, not a generic “make attention bigger” trick.
§3.4 p.6 · Eqs.8–11
MECHANISM CROWN

主要增益來自 rearrangement：把 attention 的時間歸屬重分配。
Reinforcement 只在分布太平時，補上強度。

Appendix ablation explicitly says removing rearrangement causes the larger drop; reinforcement alone lacks temporal correspondence.
§3.4 p.6 · Appendix D p.15
FULL OPERATOR

A mask gates a time-aware, strength-aware bias inside softmax

A = softmax((QKT + Ms x R(Q,K) x B(Q,K)) / sqrt(d))
  • Ms: where to intervene — motion regions only.
  • B(Q,K): which event should own this temporal segment.
  • R(Q,K): how strongly to act when attention is flat.
  • softmax preserves a soft distribution rather than hard-blocking all context.
§3.4 p.5 · Eq.3

WHY THE MASK MATTERS

Without MRE, background tokens become collateral damage

“More control” is not enough. The intervention must know where not to act.
§4.4 p.9 · Figure 7 pp.14–15
ROBUSTNESS

Segmentation quality is a low-sensitivity knob

SUPPORTED CHOICES

  • Uniform segments by number of events.
  • User-provided interval ratios.
  • GPT-4o-mini event planning (about 2–3 s per prompt).

PAPER’S INTERPRETATION

  • Final-performance differences are minimal.
  • Overlapping event intervals do not significantly hurt performance.
  • Soft redistribution guides a primary focus, not total event isolation.
Appendix E p.16 · Figure 8 p.16
SCOPE / LIMITS

The paper is explicit about the boundary conditions

  • Main method exposition is single-subject; multi-subject use sums each subject’s mask and modulation terms, without recomputing the attention matrix.
  • Van’s standard generation length is described as up to about 5 seconds and no more than 5 reasonably expressed events.
  • For more events, the paper applies TS-Attn to LongCat-Video-13.6B and splits 9 events into 3 clips.
  • A temporal plan is still required — robustness to coarse segmentation is not the same as removing planning.
Appendix A p.14 · Appendix I pp.17–18 · Appendix E p.16
APPENDIX · AUTHOR WORDING

Three lines worth keeping

“TS-Attn first extracts and thresholds the cross-attention map associated with the event-performing entity to identify the motion-related regions.”

先定位執行事件主體所對應的 motion region，再決定在哪裡修改 attention。§1 p.2

“Attention rearrangement contributes more to performance improvement... attention reinforcement... serves more as a supporting component.”

重排是主要機制；強化是依分布狀態調節的輔助機制。Appendix D p.15

“TS-Attn only requires a rough temporal segmentation to effectively perform reasonable attention reallocation.”

時間切分可以粗，但 attention 的重新分配必須對。Appendix E p.16

Takeaway

Multi-event video generation does not necessarily need a new model or a new training run. TS-Attn changes the temporal ownership of attention where motion happens.
