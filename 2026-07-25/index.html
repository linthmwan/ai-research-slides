P2P: Automated Paper-to-Poster Generation and Fine-Grained Benchmark

Tao Sun, Enhao Pan, Zhengkai Yang, Kaixin Sui, Jiajun Shi, Xianfu Cheng, Tongliang Li, Wenhao Huang, Ge Zhang, Jian Yang, Zhoujun Li
ICLR 2026 PosterarXiv:2505.17104Multi-agent HTML poster generation

一篇把 academic poster generation 拆成 Figure Agent → Section Agent → Orchestrate Agent 的多代理系統論文，並同時提出 instruction dataset 與細粒度評測。

Source: arXiv v1 2025-05-21; OpenReview forum JojyT9niJL; PDF/raw ingested locally.
TL;DR

P2P 的關鍵不是「讓 LLM 寫海報」，而是把海報製作拆成可檢查、可反思、可評分的 multi-agent workflow。

視覺抽取、內容規劃、HTML/CSS 組版各自有 checker；P2PEval 再用 Universal + Fine-Grained 評測把「像不像官方 poster」量化。

Abstract p.1; Fig.1 and §2.1 p.4-5
Why this paper today?

週六主題：AI Agent 框架 / 多模態系統

  • Agentic architecture: 三個專門代理 + checker/reflection loops，而不是單次 prompt。
  • Multimodal document task: 需要同時處理論文文字、圖表、caption、layout 與 HTML rendering。
  • Evaluation-first: P2PEval 把生成 poster 的 fidelity / layout / visual-text alignment 做成可比較 benchmark。
  • 工程含義: 這篇很適合圖像/文件工程師思考「LLM 產物如何被結構化驗收」。
§1 p.3; §3 p.6-8; §4 p.8-11
Problem

Academic poster 是一個比摘要更難的 document-to-design 任務

  • 人工製作 poster 同時要求 內容取捨、視覺設計 與 圖文整合，對早期研究者成本高。
  • 傳統 template / rule-driven 方法常拆成 isolated subtasks，難保留論文的 semantic richness 與 structural nuance。
  • 既有 datasets / metrics 缺少對 poster quality 的細粒度評估，難以系統比較方法。
  • LLM/MLLM 有潛力，但缺少 quality-control mechanism 時，版面與忠實度不穩。
任務本質：不是 summarization，而是 faithful multimodal communication design。
§1 p.3; Related Work §5 p.12
Contributions

三件事一起交付：系統、資料、評測

  1. P2P framework: LLM-based multi-agent paper-to-HTML-poster architecture。
  2. P2PInstruct: 30,460 examples，覆蓋 figure description、section/content generation、HTML generation。
  3. P2PEval: 121 paper-poster pairs + Universal / Fine-Grained dual evaluation。
  4. Large comparison: 33 models / variants，包含 closed-source、open-source、reasoning mode、fine-tuned variants。

System overview

Figure 1：三代理 + 三 checker 的 closed-loop poster factory

Fig.1 p.4; §2.1 p.4-5
Agent 1

Figure Agent：把圖表從 pixels 變成可引用的 semantic visual units

  • DocLayout-YOLO 抽取 figures / tables。
  • Caption matching 透過 spatial relation analysis。
  • MLLM 生成 description，形成 visual + caption + description bundle。
Fd = {(vi, ci, desci)}
  • vi: visual element
  • ci: original caption
  • desci: MLLM-generated description
Checker 會檢查 duplicate、coverage、visual-caption pairing；count mismatch 時逐步降低 detection threshold 重新對齊。
§2.1 p.4
Agent 2

Section Agent：先推 poster schema，再寫帶圖索引的內容

Pposter_text = Mtext(D, S, Fd)
  • Section Generator 從原論文 D 推出 target poster schema S，例如 Introduction / Methods / Results。
  • Content Generator 以 D、S、Fd 產生 poster text。
  • 在合適位置插入 Markdown-style figure indices，讓文字與視覺素材對齊。
  • Section Checker 檢查 coherence、completeness、faithfulness、visual reference correctness。
§2.1 p.4-5
Agent 3

Orchestrate Agent：HTML/CSS 是最終可執行 layout

  • HTML Generator 接收 `P_poster_text` 與 extracted visuals `F_v`，同時拿到 width / height / aspect ratio。
  • 為了視覺清晰，embedded visuals 不保留原 caption。
  • 三個 rendering principles：content-structure decoupling、institutional identity alignment、responsive balanced layout。
  • Poster Checker 針對 aesthetics / structural integrity 觸發修正。
這裡的 insight 很工程化：把 poster 當作 可驗證的前端產物，不是靜態圖片。
§2.1 p.5
Dataset

P2PInstruct：把 multi-agent traces 變成 30K+ supervision

30,46016,84813,6123,300+ tok
  • 30,460 instruction-response pairs derived from P2P workflow。
  • 16,848 figure-description pairs from Figure Describer，平均 192 tokens / visual element。
  • 13,612 examples from Section Generator / Content Generator / HTML Generator。
  • Text/content responses 平均超過 3,300 tokens，反映 poster generation 的長輸出與結構複雜度。

Benchmark construction

P2PEval 的重點是 checklist，而不是泛泛打分

121 pairs1,738 items775 visualavg max 4.07
  • 121 paper-poster pairs，來自 ACL 2022-2024 與 SciPostLayout / F1000Research。
  • 四位 annotators：三人獨立 review，每個 poster 由第四人 verify。
  • Checklist items 以 1-5 importance score 標記 minor / core / critical elements。
  • 1,738 items 中 775 個關聯 visual elements，直接逼問圖像與內容 fidelity。
§3.1 p.6-7
Universal evaluation

Universal score 用人類總分校準，而非單純平均 LLM judge

  • 10 criteria：title/authorship accuracy、image quality、white space、content fidelity、information flow 等。
  • 三位 human annotators 對 posters 打 0-50 overall score。
  • 累積 1,701 independent human annotation scores。
modelR²
XGBoost0.92

§3.2.1 p.7-8
Fine-Grained evaluation

Fine-Grained score 衡量「官方 poster 的必要元素被保留下來多少」

Sfine = (sumi=1..n si / sumi=1..n Mi) x 100
  • si 是 generated poster 對第 i 個 checklist item 拿到的分數。
  • Mi 是該 item 的 maximum possible score，由多位 annotators consensus 得出。
  • 它不是 generic aesthetics score，而是對 original author communication goals 的 fidelity measure。

Limits / caution

這篇沒有明列 Limitations；但使用時要記住三個邊界

  • Judge dependency: Universal / Fine-Grained evaluation 使用 GPT-4o / VLLM judges，Universal 又由 1,701 human scores 校準 XGBoost。
  • Benchmark scope: P2PEval 的 official pairs 主要來自 ACL 2022-2024 與 SciPostLayout / F1000Research。
  • Hybrid comparison: Table 1 中 text-only LLMs 使用 Claude-3.7-Sonnet 作 Figure Describer provider，部分結果不是純單模型能力。
§3.1 p.6; §3.2.1 p.7-8; Table 1 footnotes p.9-10
Engineering takeaways

對 agent / multimodal system builder 的三個啟發

  1. 將中間物件顯式化: visual units、poster schema、poster text、HTML 都是可驗證 artifacts。
  2. 讓 checker 成為架構的一部分: 不要只在最終輸出後人工看；每個 agent 的輸出都應有 local acceptance criteria。
  3. 評測要貼近任務意圖: P2PEval 用 official poster checklist，而不是只靠 ROUGE/BERTScore 或泛用 aesthetics。
如果把這套思路放回日常 agent 工程：每一步都應留下可檢查 spec，而不是只留下漂亮 final。
§2.1 p.4-5; §3 p.6-8; §4.3 p.10-11
Appendix highlight A

核心架構原文

P2P employs three specialized agents—the Figure Agent for visual element processing, the Section Agent for content generation, and the Orchestrate Agent for final poster assembly, each paired with a dedicated checker module to enable iterative refinement and ensure output quality.

P2P 把任務拆成圖像元素、內容生成、最終組版三個代理，並在每個代理後加 checker/reflection，讓 poster 不是一次性生成，而是可回饋修正的流程。§1 p.3; §2.1 p.4-5

Appendix highlight B

P2PEval 為何比泛用分數更硬

The annotation process results in 1738 checklist items, with 775 associated with visual elements. The scoring system yields an average per-item maximum score of 4.07.

P2PEval 的細粒度評估不是抽象打分，而是把官方 poster 的圖像、內容、結構與研究重點拆成 1,738 個 checklist item，其中 775 個直接關聯 visual elements。§3.1 p.7

Appendix highlight C

Ablation 的作者解讀

This confirms our hypothesis that poster generation benefits significantly from modularized, specialized processing that mimics the distinct cognitive steps humans undertake when creating posters from research papers.

ablation 的真正訊息是：多代理不是裝飾，模組化、figure description、reflection 分別對 fidelity、layout、審美穩定性有貢獻。§4.3 p.11
