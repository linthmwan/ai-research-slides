在不知道預訓練資料時，
怎麼保護 base LLM 的通用知識？

EOUPCT 用可微 pseudo data 尋找下一次更新最可能傷到的知識邊界，再把更新投影到安全方向。

Bing Wang et al. · Jilin University / RIKEN / University of Warwick / University of Tokyo
NeurIPS 2026arXiv:2609.309352026-09-25
Estimating and Orthogonalizing Unknown Pre-training Gradients for Continual Fine-tuning of Large Language Models · Abstract p.1; NeurIPS 2026 front matter p.1
TL;DR

不要只保護「已看過的舊任務」。
EOUPCT 先估計缺席的預訓練梯度，再讓新任務更新避開它。

關鍵不是合成看似合理的 replay data，而是合成對下一個更新最脆弱的 base-model 知識。
Abstract p.1; §3.1 p.4
THE FAILURE MODE

Continual fine-tuning 同時遺忘兩種東西

  • 前序 downstream tasks：新任務梯度和歷史任務梯度互相干擾。
  • base LLM 的通用知識：常識、推理等能力來自不可取得的預訓練資料。
  • 現有 orthogonal projection 能保護已觀察到的 task gradients，卻沒有可投影的 pre-training gradient。
缺的不是另一個 LoRA adapter；是「要保護哪個 base-knowledge direction」的訊號。
§1 pp.1–2; §2 p.3
WHY PRIOR FIXES FALL SHORT

三條既有路線，各自留下缺口

路線能解什麼仍缺什麼
梯度正交 / OLoRA減少已知任務間干擾沒有未知預訓練梯度
Data rehearsal重播歷史 samples拿不到原始預訓練資料
Parameter isolation隔離新舊 task 模組需歷史模型 / routing；統一模型仍可能遺忘

EOUPCT 選擇在 gradient space 補上缺失的 pre-training protection direction。

§2 p.3
PAPER CLAIM

EOUPCT 的三個貢獻

  1. 估計：以 soft prompt + Gumbel-Softmax 從 base LLM 生成可微 pseudo pre-training sequence。
  2. 對齊：把新任務、歷史 task、估計 pre-training gradients 一起納入 Pareto orthogonal optimization。
  3. 可算：用 first-order virtual step 近似避開二階 Hessian 成本。
§1 p.2; §3.1 p.4; §3.4 p.6
METHOD OVERVIEW

一條 pipeline：找到脆弱處，再限制更新

Pseudo data 是用來產生保護梯度，不是把它當普通的 synthetic training corpus。
Fig.1 p.4; §3.1 p.4
MODULE 1 · ESTIMATE

把 frozen base LLM 當成不可見的預訓練分布模型

輸入

  • 針對目前 task t 學一段長度 L 的 soft prompt。
  • 將 prompt prepend 到原始 pre-training LLM。
  • 生成 M 個連續 token embeddings 作 pseudo sequence。

輸出

  • 比較 base LLM 與 current LLM 在 pseudo sequence 的 latent representations。
  • 其 MSE distillation loss 對模型參數的梯度，就是 estimated pre-training gradient。
Lpre = MSE(F0(S(P)), F(S(P)))   ·   gpre = gradient(Lpre)
§3.2 pp.4–5; Eq.3 p.5
WHY GUMBEL-SOFTMAX

Discrete decoding 不能拿來找保護梯度

  • 一般 top-k / sampled token 是離散選擇，soft prompt 的 gradient 在 decoder 處斷掉。
  • Gumbel-Softmax 把每一步 next-token logits 變成連續機率分布，再取 expected embedding。
  • 從 prompt 到 sequence 保持可微，才能將「哪些知識最易被遺忘」反向傳回 prompt。
soft token em = pim Wemb   (continuous surrogate, not a sampled token)
§3.2 pp.4–5; Eqs.1–2 p.4–5
MECHANISM · THE CRUCIAL MOVE

不是問「base model 知道什麼？」
而是問「這次 task update 會先傷到 base model 的什麼？」

先做 virtual update，再讓 prompt 最大化此時的 pre-training distillation loss。
§3.3 p.5; §3.4 p.6, Eq.8
MODULE 2 · VULNERABILITY

Virtual step 把二階 gradient-conflict 目標改成一階問題

  • 先用 new-task gradient 形成虛擬模型：`theta_virt = theta - alpha * g_new`。
  • 再優化 prompt，讓 pseudo sequence 在 virtual model 上的 Lpre 最大。
  • 一階 Taylor 展開顯示：這等價於找與 gnew 衝突最大的 protection gradient。
  • 不必直接對 prompt 求 Hessian，保留了方法的可用性。
EOUPCT 的 pseudo data 是 task-conditional、adversarially selected，而非 generic replay。
§3.3 p.5; §3.4 p.6, Eq.8
MODULE 3 · THREE GUARDS

三種 orthogonality 對應三種干擾

保護關係操作避免的遺忘
new ↔ old downstreamproject into historical null space前序 task
new ↔ estimated pre-trainingPareto projection if conflictbase 通用知識
pre-training ↔ pre-trainingsquared cosine penalty只保護單一脆弱區
§3.3 pp.5–6; §3.4 p.6, Eqs.9–11
OPTIMIZER

四步 first-order Pareto optimizer

  1. 以 virtual step + diversity penalty 優化 soft prompt。
  2. 把 new-task 和 protection gradients 投到歷史 task 的 null space。
  3. 若兩者相衝，從 new-task gradient 移除 protection-gradient component。
  4. 將安全 task direction 與 protection direction 合併更新模型。
update = -eta * (safe gnew + safe gpre)
§3.4 pp.6–7; Eqs.9–12

WHY IT WORKS

Ablation 的訊息很乾淨：
找得到脆弱邊界（C2）還不夠，也必須讓三種梯度不互相踩到。

尤其移除 new-new protection 在 Qwen3-4B 使 task forgetting 回升至 10.3。
Tab.2 p.9; §4.3 p.9
FORGETTING DYNAMICS

不是終點一次測試；EOUPCT 讓退化曲線更平

  • 作者沿著 sequential SuperNI tasks，持續測 Qwen3-4B 和 Llama3-3B 的 MMLU 三類 accuracy。
  • CLoRA 隨 task index 穩定下滑；EOUPCT 維持較高、較慢的下降。
  • 部分 stage 暫時高於未 fine-tune 的起點；作者將其解讀為 pseudo data + optimization 可能強化有用 representations。

最後一點是作者的 interpretation，不等於已證明普遍的 capability improvement。

§4.4 p.9; Fig.3 p.9
LIMITATIONS

用計算換掉 storage，也仍有容量上限

  • Training overhead：Gumbel-Softmax 的 autoregressive pseudo generation 增加 forward/backward latency，相較 standard LoRA 更重。
  • Finite proxy capacity：soft prompt 長度 L 與 generation length M 限制可覆蓋的 base-knowledge region。
  • Long heterogeneous streams：作者明說可能飽和；未來方向是 dynamic prompt expansion 或 hierarchical routing。
Appendix F p.22
APPENDIX · SOURCE HIGHLIGHTS

三句最值得帶走的原文

“the original data and gradients of off-the-shelf pre-training LLMs ... are strictly unknown and highly diverse.”

現成 base LLM 的預訓練資料與梯度不可得且高度多樣，因此不能直接沿用已知任務保護法。Abstract p.1

“The correct objective is to maximize the gradient conflict.”

真正要找的是即將被新更新破壞得最嚴重的知識方向。§3.4 p.6

“removing any component leads to a consistent degradation in both task-specific performance and general knowledge preservation.”

每個約束都有可測量的必要性，不是把多個 regularizer 疊在一起而已。§4.3 pp.8–9

Paper text as quoted above

EOUPCT：把
「未知的舊知識」
變成可保護的方向

對 continual LLM tuning 而言，最有價值的轉換是：從保存過去 samples，轉向估計並限制破壞性更新。
