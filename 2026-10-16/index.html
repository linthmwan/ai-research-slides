Differentiable Bit-Widths

Co-optimizing Pruning and Quantization via SVD for Ultra-Efficient LLM Compression

Hankyul Kang · Jongbin Ryu · Ajou University
NeurIPS 2026 · acceptedarXiv:2610.06026v1 · 2026-10-05
Source: paper p.1–2 · https://arxiv.org/abs/2610.06026v1
THE THESIS

在極低 bit 下，先剪再量化不是最佳化；把「是否留下」也當成可學的 bit allocation 才是。

DBW uses 0-bit as pruning and positive integer bits as quantization under one fixed budget.
Abstract p.1 · §1–2 pp.1–4
DEPLOYMENT PRESSURE

問題不是只把 weights 變小

  • LLaMA-7B FP16 約 12.31 GB；若要放進 2 GB laptop GPU，目標約 1.56 GB。
  • 超過約 3–4x 壓縮時，LLM 品質通常會急遽下降。
  • SVD 同時能減 memory 與 compute，但極限 regime 還要面對每個 component 的 precision 分配。
Ultra-efficient compression is a coupled storage-and-capacity problem, not a single quantizer setting.
§1 p.1
FAILURE MODE

Sequential pipeline 把耦合的決策拆壞了

  • pruning ratio 越高，留下的 component 就越值得高 precision；反過來也成立。
  • sequential pipeline 的量化階段無法取回 pruning 已丟掉的 representation。
§1 pp.1–2 · Fig.1 p.2
DESIGN MOVE

把 SVD component 的 precision 變成一個 zero-inclusive decision

  1. SVD 分解每個 weight matrix，將 U:,c 與 V:,c 視為 component c。
  2. 學習 component bit width beta_c；positive bit 用 LBQ quantize。
  3. beta_c = 0 時，component 直接移除：這就是 rank truncation。
  4. 同一條規則同時決定「留多少 rank」與「每個 rank 幾 bit」。
§2.1–2.2 pp.2–3
METHOD · DBW

Differentiable Bit-Width：讓 discrete bit 仍可被 gradient 找到

  • 直接枚舉 B 個 candidates、C 個 components 需要 O(BC) 搜尋。
  • DBW 用 STE 穿過 floor，再以 budget-aware projection 把 continuous widths 落到 integer bits。
§2.1–2.2 p.3 · Fig.2 p.3
METHOD · BUDGET

先分 continuous budget，再做 exact integer projection

BQ(beta_c, alpha) = floor(alpha · ReLU(beta_c) / Sum_i ReLU(beta_i))
  • ReLU 保證 non-negative；normalized beta 讓所有 component 共享 matrix-level budget alpha。
  • floor 後的 remainder 由 Hamilton largest-remainder rule 分配，故總 bit budget 不漂移。
  • block-wise calibration 只訓練 target block，最小化 compressed output 與 original output 的 MSE。
§2.2 p.3 · §C.2 pp.16–17
METHOD · BI-LEVEL

不是只學 component bits；matrix budget 也要能移動

BA(alpha_m) = T · alpha_m / Sum_i alpha_i
  • component-level beta：同一 matrix 內，誰該拿 0/1/2/... bits。
  • matrix-level alpha：不同 projection matrix 之間，誰更值得拿總 budget。
  • alpha 只帶來小量訓練開銷，paper 指出推論時可保存，沒有額外 inference compute。
§2.2.1 p.4
METHOD · SHAPE THE SPECTRUM

Entropy loss 讓可安全截斷的 tail 更明顯

L_ent = - Sum_i sigma_hat_i log(sigma_hat_i) ··· optimize L_rec + L_ent
  • 最小化 normalized singular values 的 entropy，將 energy 集中到較少 component。
  • 低 entropy spectrum：少數 dominant components 值得高 precision；tail 可為 0-bit。
  • singular values 可 absorbed into quantization parameters，因此沒有新增推論計算。
§2.2.2 p.4
SERVING

Mixed precision 不該換來不規則的 kernel

  • 同 bit components 排序、packing；避免 unstructured pruning 的 irregular layout。
  • 不同 bit group 的 GEMM parallel launch，partial outputs 再累加。
  • 多個小 kernel 的 runtime 可接近 single large kernel；長 context 時節省更明顯。
§2.3 pp.4–5 · Fig.3 p.4
EXPERIMENT PROTOCOL

有刻意把 comparison 壓在極端的 1.61 bpw

  • LLaMA-1/2/3：7B–70B。
  • WikiText-2、C4 perplexity。
  • 8 個 zero-shot commonsense benchmarks。
  • RedPajama-1T：4,096 samples。
  • sequence length 2,048。
  • group size 128，target 1.61 bpw。
這不是只比一個 checkpoint；paper涵蓋 10 個 evaluation benchmarks 與多個 scale。

MECHANISM · CROWN PAGE

SVD entropy 決定「該多剪」還是「該多給 bit」

低 entropy：uniform quantization 不夠保護 dominant components。
高 entropy：truncation 會刪掉均勻分散的資訊。
§C.1 p.15 · Fig.7 p.15
MECHANISM · ADAPTIVE THRESHOLD

0-bit boundary 應隨 spectrum 移動，不應固定

  • static rule 對所有 matrix 套同一 precision boundary。
  • DBW 以 reconstruction objective 學 component widths，讓 effective threshold 隨 singular-value distribution 變動。
§C.1 pp.15–16 · Fig.8 p.16
MECHANISM · OBSERVED ALLOCATION

學到的 bit pattern 確實追著 entropy 走

  • low entropy：few leading components survive，tail 多為 zero-bit。
  • high entropy：positive bits 覆蓋較廣 component range。
§3.2 p.8 · Fig.6 p.8

LIMITS

要注意：它目前不是 universal compression proof

  • 作者明列：實驗僅限 language models；vision、speech、multimodal 還需驗證。
  • non-LLaMA 僅是 initial sanity check，不是 exhaustive study。
  • short context 時 DBW 會因 multi-kernel launch overhead 略慢於 OmniQuant。
  • 1.61 bpw 的巨大收益有強 benchmark support；但部署仍應重測自己的 architecture、context profile 與 kernel stack。
§3.2 p.7 · §5 p.9
ENGINEERING TAKEAWAY

把 compression budget 從「每層一個固定 bit」升級成「以 component entropy 為訊號的可學資源分配」。

The technical win is the coupling: rank, precision, packing, and kernel execution are designed together.
§2 pp.2–5 · §C.1 pp.15–16
PAPER HIGHLIGHTS

作者原文的三句核心斷言

“By completely discarding the 0-bit components, we perform rank truncation.”

0-bit 不是一種極低精度；它就是把該 SVD component 拿掉。§1 p.2

“This process precisely aligns the quantization resolution with the specific entropy of each of the SVD components.”

precision allocation 的對象是 component 的資訊密度，而不是 layer-wide 的固定設定。§2.1 p.3

“Hamilton gives a deterministic budget-preserving projection and yields stable final performance.”

將 continuous allocation 落到 integer bit budget 的投影方式，直接影響最終品質。§C.2 p.16
