SliderQuant

把「量化時每層都一樣」這個假設拆掉：以層敏感度驅動的 LLM PTQ。

Shigeng Wang et al. · Intel Labs China / BUPT
ICLR 2026arXiv:2603.25284
Source: Paper p.1; Fig.2 p.5 · Deck date 2026-09-11
TL;DR

低位元 PTQ 的問題，不是每一層都同樣難量化。

SliderQuant 反覆照顧最敏感的首尾層，並讓相鄰窗重疊傳遞校正；核心是adaptive schedule，不是更大的單一 window。

Abstract p.1; §1 pp.2-3
THE DEPLOYMENT PROBLEM

PTQ 省掉重訓，但低位元誤差會累積

  • PTQ 用少量 calibration samples，把既有高精度 LLM 直接替換成低精度版本。
  • 它可降低推論的記憶體與計算需求；但 W4A4 等 aggressive setting 很容易讓生成與推理能力崩落。
  • 傳統 sequential PTQ 把模型切成相同大小的層／block，從前到後各自量化。
真正要問的是：哪些層最不能被一視同仁？
§1 p.1; §4 p.6
EMPIRICAL CLUE

首尾層是誤差熱點；中間層相對容易

作者在 Llama2-7B / 13B 與 Qwen2.5-14B 觀察到：shallow/deep layers 通常更敏感，first/last layer 又是峰值。

Fig.1 p.2; §1 p.2
MECHANISM CROWN

讓敏感層在更多重疊窗口裡被共同校正，取代全模型同一種量化步調。

相鄰窗口重疊形成 error-relay；對首尾層額外加密的視野，才是它能在低 bit regime 留住能力的假說。

§1 pp.2-3; §3.2 p.5
BASELINE

Fixed-size sliding quantization：有重疊，但還不夠自適應

overlap = s - i
  • Window size = s; move interval = i.
  • 在當前窗口，最小化高精度與量化後 window output 的 MSE。
  • 當 i = s 時，退化成不重疊的 layer/block/multi-block PTQ。
min ||F(W, X) - F(W_hat, X)||22
  • 更大 window 通常提高 accuracy。
  • 代價是 calibration-time memory cost。
  • 固定 s、i 仍假設所有深度位置同樣重要。
§3.1 p.4
METHOD / INTER-S

三段式 inter-layer schedule：首尾加密，中段穩定

  • PESW：shallow region 從第一層開始逐步擴張，first layer 每次都在窗口內。
  • FSSW：middle region 使用固定 s=2, i=1，提供均勻更新頻率。
  • PCSW：deep region 逐步收縮，last layer 每次都在窗口內。
Fig.2 p.5; §3.2 p.5
METHOD / PESW + PCSW

錨定首尾層，讓 local-to-global / global-to-local synergy 成形

Shallow: PESW

  • 由 size 1 開始，每步加 1。
  • 第一層是 anchor，出現在每個擴張窗口。
  • 目的：緩和 shallow layers 的量化誤差。

Deep: PCSW

  • 先覆蓋所有 deep layers，再逐步減 1。
  • 最後一層是 anchor，出現在每個收縮窗口。
  • 目的：緩和 deep layers 的量化誤差。
§3.2 p.5
METHOD / INTRA-S

窗口內也分 stage：先半量，再共同重建

N = 1 / gamma
  • 每個 inter-layer window 在 weight/activation 維度內，以 ratio gamma 漸進量化。
  • 預設 gamma=0.5，因此 N=2 個 stage。

Two-stage default

  1. Stage 1：聯合量化 current window 的前半矩陣。
  2. Stage 2：聯合量化完整矩陣，包含第一階段已處理部分。
  3. 結果：在 window 內建出 local-to-global parameter synergy。
§3.2 p.5
METHOD / QUANTIZER

CS + low-rank refinement：先處理 outliers，再做 uniform quantization

X_tilde = X / alpha ; W_tilde = W * alpha + AB ; X_next = quantize(X_tilde) * quantize(W_tilde)
  • learnable channel scaling alpha 壓低 activation outliers，並反向調整 weights。
  • low-rank A,B 修正量化前 weight；實驗採 rank r=4。
  • 預設 calibration samples c=128；weight 與 activation 都用 uniform quantizer。

ENGINEERING INTERPRETATION

把 calibration compute 花在「高敏感度的層關係」上，比均勻地加大所有窗口更划算。

這是一個 deployment-facing 的設計語言：先量測 sensitivity map，再讓 schedule 對稱或不對稱地配合模型深度，而不是只追 quantizer 的局部 loss。

§1 pp.2-3; Tables 9-11 p.10
LIMITS

論文已展示 accuracy；實務還要補 serving 成本的帳

  • 作者明示：增大 Ls, Ld 會提高 quantization-time memory 與 compute；預設 4 是折衷。
  • 主文的精度比較很廣，但沒有提供 end-to-end serving latency、kernel efficiency 或硬體能源量測。
  • SliderQuant+ 加入 rotation 以便與 cost-bearing methods 公平比較；應與無額外 inference cost 的版本分開讀。
§4 pp.6-7; §4.2 pp.9-10
