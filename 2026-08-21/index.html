NanoQuant: Efficient Sub-1-Bit Quantization of Large Language Models

Hyochan Chong, Dongkyu Kim, Changdong Kim, Minseop Choi · Samsung Research
ICML 2026arXiv:2602.06694v3Accepted · 14 Jun 2026

一個把 LLM 壓到 1-bit / sub-1-bit 的 PTQ pipeline：LB-ADMM 初始化、block reconstruction、scale-only global calibration。

TL;DR

NANOQUANT 的重點不是「硬把權重變 1-bit」；而是把 dense weight 改寫成 兩個 binary low-rank factors + channel scales。

這讓 PTQ 可以跨過 in-place binarization 的 1-bit 下限，同時把 70B compression 留在單 GPU 預算裡。
Abstract p.1; Intro p.2; Conclusion p.9
Problem

現有 binary PTQ 有兩個卡點：表示法下限 + metadata overhead

  • In-place binarization 通常是 W ≈ alpha B，結構上至少 1 bit/parameter。
  • Binary PTQ 還常需要複雜 grouping metadata，effective bitrate 可能超過 2 或 3 bits。
  • Binary/sub-1-bit QAT 雖能用 low-rank representation，但常要 100M-1B+ tokens、多 GPU、多天訓練。
  • 所以真正缺的是：小 calibration set + 單 GPU 可跑的 sub-1-bit PTQ。
問題不是量化位元本身，而是「表示法」與「初始化」讓 PTQ 被卡住。
§1 p.1-2
Contribution

四個貢獻，對應四個工程痛點

  1. Representation: 低秩二元分解，支援 1-bit 與 sub-1-bit。
  2. Initialization: Hessian-aware LB-ADMM，讓 PTQ 不靠大量 retraining 也能進入好 basin。
  3. Reconstruction: block-wise STE refinement + scale-only model calibration，控制誤差傳播。
  4. Kernels: binary GEMV/GEMM CUDA kernels，讓壓縮真的變成 throughput / memory / energy gain。
Contributions p.2; §4.4 p.7
Method 1 · Quantization scheme

Dense W 被拆成二元方向與尺度：storage 的主體變成 bit-packed factors

W_hat = s1 ⊙ (U±1 V±1T) ⊙ s2T
  • U±1 ∈ {-1,+1}d_out x r，V±1 ∈ {-1,+1}d_in x r。
  • s1, s2 分別吸收 output / input channel magnitude。
  • rank r 控制 bits-per-weight；低 rank 讓 effective storage 可以低於 1 bit。
binary factorsFP scalesrank rsub-1-bit

Method 2 · Three-phase pipeline

NANOQUANT 把 combinatorial binary factorization 塞進 block reconstruction loop

  1. Error propagation mitigation: 先調整 current FP block，抵銷前面已壓縮 blocks 的誤差。
  2. Low-rank binary initialization: Hessian-aware preconditioning + LB-ADMM + magnitude balancing。
  3. Factorized refinement: 用 STE 微調 latent U,V,s1,s2，對齊 full-precision block outputs。
  4. Scale-only model reconstruction: packed binary weights frozen，只調 global scales 對齊 logits。
先讓 factorization 接近，再做局部與全域修復；不是直接 sign(W)。
§3.2 p.3-5; Algorithm 1 p.5
Method 3 · LB-ADMM

Hessian-aware 初始化：用 curvature 權重定義「哪裡錯比較痛」

L(W_hat) ≈ || Dout (W - W_hat) Din ||F2
  • Din, Dout 來自 activation / gradient statistics，並用 shrinkage 抑制 calibration noise。
  • ADMM 用 auxiliary variables 與 dual variables，把 continuous reconstruction 跟 binary-structure constraint 拆開。
  • U/V update 解 regularized linear system；stabilized Cholesky 把 rank-r solve 從 LU 的 O(2r3/3) 降到 O(r3/3)。
§3.2 p.4
Mechanism crown

這篇真正的 mechanism 是：好初始化 讓小資料 PTQ 不必靠 QAT 的海量 token 來救。

LB-ADMM 先找到可微調的 low-rank binary basin，STE refinement 才有東西可修。

Scale ambiguity

Magnitude balancing 解掉 UV^T 的任意縮放自由度

UVT = (ηU)(η-1V)T, η* = sqrt(||V||F / ||U||F)
  • 低秩分解有 scale ambiguity：同一個 W_hat 可由無限多組 U,V 表示。
  • 若不平衡，某個 factor 過大、另一個過小，scale extraction 會變得 ill-conditioned。
  • Appendix A 證明 η* 會最小化 total factor magnitude，並讓兩個 factor 的 Frobenius norm 相等。
§3.2 p.4-5; Appendix A p.14

How to read the claims

這篇最值得學的是「PTQ 公式化」與「hardware-aware representation」

  • Representation-first: 如果 representation 的 metadata overhead 太大，名義 1-bit 沒有意義。
  • Initialization-first: extreme compression 的 optimization landscape 太差，先求好 binary latent basin 才是關鍵。
  • Reconstruction hierarchy: layer/block/model 三層修復處理不同誤差，不要期待單一 global tuning 補完。
  • Kernels are part of the method: 沒有 binary GEMV/GEMM，storage gain 不一定轉成 serving gain。
對 image/video model compression 也一樣：先問 representation 是否真的省、初始化是否穩、kernel 是否吃得到。
§3 p.3-5; §4.4 p.7
Limitations

作者自己承認的邊界

  • 更多 data / compute 可能會進一步改善複雜 reasoning tasks。
  • Custom CUDA kernels 還需要針對 Blackwell 或 edge-specific hardware 進一步優化。
  • Sub-binary regime 尚未全面打贏 2-bit / 3-bit PTQ；這仍是 future work。
  • Binary PTQ baseline kernels 不可用，因此 inference 比較主要是 BF16 與 vector quantization baselines。
§4.4 p.7; §4.6 p.9
