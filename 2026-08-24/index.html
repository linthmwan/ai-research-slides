GVPO: 用 group variance 穩住 LLM post-training

Kaichen Zhang, Yuzhong Hong, Junwei Bao, Hongfei Jiang, Yang Song, Dingqian Hong, Hui Xiong
NeurIPS 2025 posterarXiv:2504.19599v32026-08-24 · Monday LLM

主問題很直接：GRPO 類 LLM RL 好用，但 off-policy / clipping / KL 係數讓訓練脆。GVPO 把 KL-constrained optimal policy 的閉式解塞進 group-wise 權重，試圖同時拿到穩定性與 sampling 彈性。

Sources: arXiv 2504.19599v3; OpenReview NeurIPS 2025 poster; raw p.1
TL;DR

GVPO 把「reward 差距」改寫成「group 內 centered implicit reward 要貼近 centered actual reward」。

結果是：partition function 會被 zero-sum weights 抵消；sampling distribution 不必綁死 on-policy；Var/Cov 兩個正則項由推導自然長出來。
Abstract p.1; §3.1-§3.3 p.5-p.6
Problem

GRPO 的吸引力：省掉 value model；GRPO 的麻煩：訓練不穩

  • GRPO 用 group relative reward 直接做 advantage，不需要另外訓練 value model，這是 DeepSeek-R1 類 RLVR 管線有吸引力的原因。
  • 但 paper 指出 GRPO 對 clip threshold 和 KL coefficient 敏感；negative likelihood / clipping / KL 約束都會讓穩定性變成工程調參問題。
  • off-policy 時若用 importance weight πθ/πold，policy drift 會造成 gradient explosion；clip 又會引入 bias。
GVPO 的設計目標不是再調一個更好的 clipping trick，而是換掉權重設計本身。
Introduction p.1-p.3; §2.1 p.3; §3.5 p.8
Unifying lens

把 SFT / GRPO / DPO 都看成 weighted log-likelihood gradient

∇L = - Σi wi ∇ log πθ(yi|x)
  • SFT：一個標準答案，weight = 1。
  • GRPO：同一 prompt 下多個 response，用 standardized reward score 當 weight。
  • DPO：preferred / dispreferred pair 的 weight 互為正負。
  • 所以 GVPO 的切入點是：直接設計 wi，而不是先訓 reward model 再套傳統 RL。
§2.3 Unified framework of post-training p.4
Core trick

zero-sum group weights 讓 partition function 消失

Rθ(x,y) = β log(πθ(y|x) / πθ′(y|x)) + β log Z(x)
  • DPO 的成功來自把 KL-regularized reward maximization 的 closed-form optimal policy 放進 loss。
  • 問題是 Z(x) 需要對所有 response 求期望，實務上不可估。
  • GVPO 要求每個 prompt group 的 weights 滿足 Σiwi = 0。
  • 因此 Σiwi β log Z(x) = 0，partition function 在 update rule 裡自然抵消。
§3.1 Motivation p.5; §3.4 p.6
Method

GVPO 權重 = centered actual reward - centered implicit reward

wi = (Ri - mean(R)) - β[(log ratioi) - mean(log ratio)]
  • log ratioi 是 log πθ(yi|x) / πθ′(yi|x)，對應 implicit reward。
  • 同一 prompt group 內做 centering，保證 Σwi=0。
  • 高 reward response 被推高 likelihood；低 reward response 被壓低，但 weight 同時受到目前 policy ratio 的校正。
§3.2 Eq. 8 p.5

Algorithm

訓練 loop 跟 GRPO 很像，但 loss 裡多了 old/current log-prob 幾何

  1. 抽一批 prompts Db。
  2. 把 old policy 更新成目前 policy：πθold ← πθ。
  3. 對每個 prompt 從 sampling policy πs 抽 k 個 responses。
  4. 計算每個 response 的 reward。
  5. 用 Eq. 8 的 GVPO loss 反覆更新 policy，通常設 πθ′ = πθold。
最重要的自由度是 πs：它不必等於目前 policy。
Algorithm 1 p.4; §4 setup p.9
Mechanism crown page

GVPO 的穩定性來自一個 MSE：讓 policy ratio 隱含出的相對 reward 幾何，貼近真實 reward 幾何。

如果 implicit reward 和 actual reward 只差 group-level constant，loss 就最小；這剛好避開了不可估的 partition function。
§3.2 p.5
Theory

唯一最優解 = KL-constrained reward maximization 的最優 policy

π* (y|x) = (1 / Z(x)) πθ′(y|x) exp(R(x,y)/β)
  • Theorem 3.1：最小化 GVPO surrogate 的唯一 policy，就是上面這個 KL-constrained optimal policy。
  • 唯一性讓 objective 不只是 heuristic；它在理論上對齊原本的 constrained reward maximization。
  • DPO 也利用 closed-form solution，但 Bradley-Terry pairwise model 可能帶來 multiple minimizers；GVPO 用 group zero-sum 走另一條路。
Theorem 3.1 §3.3 p.6; §3.4 p.6-p.7
Off-policy

Theorem 3.2：sampling distribution 可以換，只要 support 覆蓋 reference

support(πθ′) ⊆ support(πs)
  • 這個條件對 softmax LLM policy 通常溫和：只要 reference 可能產生的 response，sampling distribution 也不能完全排除。
  • 因此 GVPO 能用 reusable / mixed / historical data，而不用每次都從 current policy 取 fresh trajectories。
  • 它也不需要 πθ/πs importance ratio，所以避免 ratio explosion 與 clipping bias。
Theorem 3.2 §3.3 p.6; §3.5 p.8
RL decomposition

GVPO = advantage + Cov trust-region + Var balance

  • Advantage term：(R - mean R) log πθ，推高 group 內高 reward response。
  • Cov term：Cov(log πθ, log πθ′)，約束 policy 不要偏離 old/reference，類似 trust-region。
  • Var term：Var(log πθ)，在 exploration/exploitation 間取得穩定平衡，不靠手調 entropy coefficient。
後面的 ablation 顯示：這兩個 regularizer 不是裝飾，拿掉就壞。

Implementation

最小可行實作：在 GRPO loss 裡替換幾行權重邏輯

loss = -β · score · [adv - β((scorenew-mean) - (scoreold-mean))]
  • Appendix 的 verl snippet 只改 policy loss：取 sequence log-prob / old log-prob、做 group mean centering、乘上 reward advantage。
  • 作者特別註明：input batch 要對應同一 prompt 的 k responses；GRPO advantage calculation 的 std normalizer 要拿掉。
  • 這使 GVPO 比「重新搭一套 RLHF 框架」更像是現有 GRPO pipeline 的 loss-level 替換。

Engineering read

如果你已經有 GRPO/RLVR 管線，GVPO 最值得測的是「是否能用 replay / mixed sampling 降低 rollout 成本而不炸」。

這比單純追 AIME 分數更有工程含金量：Theorem 3.2 給它一個 off-policy sampling 的理論入口。
Theorem 3.2 p.6; Fig. 4 p.9
Appendix highlight 1

Partition function cancellation

“when the sum of assigned response weights within a prompt group equals zero, the partition function becomes invariant across compared responses, effectively canceling out in the policy update rule.”

當同一 prompt group 的權重和為 0，閉式最優策略裡最麻煩的 partition function 會在比較中抵消，這是 GVPO 可實作的關鍵。Introduction p.2 / §3.1 p.5

Appendix highlight 2

MSE interpretation

“GVPO’s gradient mathematically equals that of a mean squared error loss measuring the discrepancy between implicit and actual reward central distances.”

GVPO 不是只調一個 heuristic 權重；它等價於讓 policy ratio 隱含出的相對 reward 幾何去貼近真實 reward 幾何。§3.2 p.5

Appendix highlight 3

Sampling flexibility

“GVPO retains the theoretical guarantee of a unique optimal solution under any sampling distribution that satisfies a mild condition.”

只要 sampling distribution 的 support 蓋住 reference policy，GVPO 就保有唯一最優解，這讓 off-policy / replay / 混合資料成為理論上合理的選項。§3.3 p.6

Appendix highlight 4

Regularizers are necessary

“In both cases, the model fails to converge and generates incoherent outputs, indicating that each term plays a crucial role in stabilizing training.”

拿掉 Var 或 Cov 都直接訓練失敗，表示穩定性不是加分項，而是 GVPO 這個 objective 站得住的必要結構。Table 2 analysis p.10
