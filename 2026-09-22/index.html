4DGS-Fixer

以 dense geometry + reference-guided video restoration 修補 sparse-view 4DGS。

Haitao Huang et al. · Goertek Alpha Labs / Singapore Institute of Technology / HKUST
SIGGRAPH Asia 2026 TCarXiv 2609.21176v1
Paper: 4DGS-Fixer: Generative Sparse-View 4D Gaussian Splatting with Iterative Refinement Guided by Video Diffusion Priors · p.1 · arXiv:2609.21176v1
TL;DR

先補齊「看得到」的幾何，再用被觀測視角錨定的 video restoration 補「看不到」的 trajectory。

優化的是 4DGS field；diffusion model 提供的是可反覆蒸餾回去的 pseudo-supervision。
Abstract p.1; §3.2 p.3
Problem

四個 input views 為什麼不足以重建動態場景？

  • 大面積場景區域會是弱觀測或完全缺失，問題本身 ill-posed。
  • limited overlap、non-rigid motion、self-occlusion、low texture 會讓 COLMAP triangulation 不可靠。
  • Gaussian densification 主要從既有 primitives 長出來，無法自然填補初始化就缺的區域。
單靠 observation-fitting 的 4DGS optimizer，沒有證據可恢復缺失視角。
§1 p.1
Prior gap

為何不只加一個 generative prior？

Sparse 4DGS
  • 常以 geometric priors、adaptive optimization、density control 緩解 sparse views。
  • 仍受輸入影像裡的 visual evidence 上限約束。
Existing generative reconstruction
  • 許多方法聚焦 static scenes。
  • 文中列舉的 dynamic approach 則限於 human-centric scenes。
本篇將「initial support」與「missing observations」拆成兩個不同的失敗模式處理。
§1 p.1; §2.1 p.2
Contributions

兩階段、但兩個訊號都回流到同一個 4DGS representation

  1. Dense geometry: MVSAnywhere depth maps -> fused colored point clouds。
  2. Novel trajectories: 在 camera pairs 之間渲染、修復、再蒸餾。
  3. Cached pseudo-targets: 降低 repeated diffusion cost 與 target drift。
  4. Empirical result: Neural3DV 24.18 PSNR，較 4C4D 多 1.89 dB。
§1 pp.1–2; Table 1 p.4

Stage 1

Dense geometric initialization

Inputs
  • COLMAP 只在 first timestamp 估 cameras。
  • 四個 cameras 固定，參數跨 timestamps 共用。
  • 每個 timestamp 的四張 synchronized frames 送入 MVSAnywhere。
Output
  • 每個 view 一張 depth map。
  • back-project + filtering/fusion 形成 dense colored point cloud。
  • 再以 original STGS objective 優化為 initial dynamic field G。

Stage 2 / trajectory

六條 pairwise paths，把 supervision 放到稀疏區

  • 四個 cameras 形成 six pairwise trajectories。
  • centers 做 linear interpolation；rotations 做 SLERP。
  • straight trajectories 設 A = 0；two diagonal pairs 加 A > 0 的 baseline-normal perturbation 以提高 spatial coverage。
cij(alpha) = (1-alpha)ci + alpha cj + A sin(pi alpha)nij
Eq. 3, §3.2 p.3
Stage 2 / restoration

CogVideoV2V 的輸入有三部分，不是無條件 hallucination

Current field supplies
  • 在 sampled novel trajectory 上的 rendered sequence Vren。
  • 這裡會暴露 blur、holes 或 view inconsistency。
Observed anchors supply
  • camera pair 兩端的 observed frames。
  • pretrained reference-guided video restorer 產生 eV 作 pseudo-target。
anchors 的角色是把生成先驗接回已觀測視角，而不是讓它自由改寫場景。

Optimization

生成的影片不是 final output，而是 4DGS 的訓練訊號

Ltotal = LSTG + lambdagenLgen    (lambdagen = 0.5)
  • LSTG 維持 observed-view reconstruction。
  • Lgen 對 cache 取樣的 novel-view pseudo-targets 做 supervision。
  • 真正更新的是 G：同一個 spacetime Gaussian representation 要同時滿足觀測與生成補足的約束。
Algorithm 1; Eq. 4, §3.2 p.3
Cache design

每 K steps refresh：成本與一致性的折衷

若每 iteration 都 call diffusion
  • 計算昂貴。
  • generation stochasticity 會讓 successive pseudo-targets 不一致。
Paper 的 cache policy
  • restored videos reuse 多個 optimization steps。
  • field 改善後每 K iterations refresh，讓 targets 跟 current render 對齊。
§3.2 p.3
Mechanism / crown page

4DGS-Fixer 的增益來自「把生成補全變成可反覆校正的 3D/4D constraint」，不是只對輸出影片做 post-process。

Dense MVS 支撐 observed geometry；anchor-guided restoration 提供 intermediate novel-view constraints；cache 讓它們可以穩定蒸餾回 field。

What the paper does not claim away

限制仍集中在生成監督的成本與可靠性

  • refinement stage computationally expensive。
  • pseudo-supervision 可受 imperfect generation 影響。
  • future work: 更有效率、也更可靠的 supervision，並擴到 diverse real-world scenes。
這份實驗支持 Neural3DV protocol 下的結果；不等於已證明所有 real-world sparse capture 都被解決。
§5 p.4
Engineering reading

可遷移的設計原則：把 expensive generative model 放進 teacher loop

  1. 先明確區分 support failure（幾何根本沒有）與 evidence failure（新視角沒有觀測）。
  2. 用 known observations 當 restoration anchors，避免 pseudo-target 完全脫離 scene identity。
  3. cache / refresh schedule 是 supervision policy 的一部分，不只是 acceleration trick。
  4. 需要檢查 teacher 的提升是否真的回寫到 representation；本篇以 full-field metrics 與 second-round restoration 共同呈現。
Synthesis from §3.1–3.2 pp.3 and Table 2 p.4
Appendix / abstract highlight

Pseudo-supervision 的原文定義

The restored sequences serve as pseudo-supervision to regularize and iteratively refine the 4DGS representation.

修復後序列不是交付物，而是用來正則化並反覆更新 4DGS 表示的偽監督。

這句話決定了整篇的讀法：diffusion 是 training signal generator，4DGS 才是被持續更新的場景模型。

Abstract p.1
Appendix / cache highlight

為何要 cache restored videos？

We therefore cache the restored videos and reuse them for multiple optimization steps.

因此作者快取修復後影片，並在多個 optimization steps 重複使用。

  • 避免每一步都付出 CogVideoV2V cost。
  • 降低 stochastic generation 造成 successive pseudo-targets 不一致的風險。
  • 每 K iterations refresh，讓 target 重新對齊逐漸改善的 renderings。
