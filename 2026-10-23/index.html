把 2-bit ViT 權重量化，從「逐 scalar 擬合」換成保留投影方向。

Paper cover p.1 · arXiv:2610.04457
TL;DR

2-bit 的問題不只在幅度誤差。
ViT 更怕方向被量化到歪掉。

RPFQ pairs channels into 2D planes, learns a local phase frame, then recovers magnitude with least-squares and a residual phase stage.
Abstract p.1 · §3 pp.3-5
01 / THE LOW-BIT WALL

ViT 的投影方向一歪，attention 的誤差會放大

  • Q-K inner products、token mixing 與深層 residual blocks 都對低位元擾動敏感。
  • 既有 QAT 多從 attention distortion 或訓練 oscillation 補救，但維持實數 scalar codebook。
  • 這篇把問題改寫為：在極低 bit 下，能不能先守住局部方向結構？
§1 p.1 · §2.1 pp.2-3
02 / CLAIMS

這不是 complex ViT；它是一個 layout-preserving quantizer

  1. Pair: 把偶數維的兩半 channel 固定配對成 2D plane。
  2. Frame: 每個 group 學 rotation 與 phase anchors，讓 2-bit directions 對準局部幾何。
  3. Recover: 以 least-squares scale 與 residual phase 補回 magnitude。
  4. Deploy: 只替換 QAT 的 nn.Linear；attention、norm、activation 都不改。
§1 p.2 · §3 pp.3-5

05 / PAIRED REPRESENTATION

先改座標，不改原本的 real-valued operator graph

xc = x1:m + i xm+1:2m;   yc = Uxc + Wx̅c
  • 把 channel j 與 j+m 固定配對；不需要 learned matching 或 routing。
  • 一個 complex coordinate 對應一個 2D direction。
  • U、W 與原實矩陣 R 有 exact mapping 與 inverse mapping。
  • 量化後重建 R-hat，再走標準 real F.linear。
§3.1 pp.3-4 · §3.2 p.5 · App. A.1 p.11
06 / WHAT 2 BITS MEAN HERE

四個 phase direction 是一個 group-local codebook

CPhi = {+1, -1, +i, -i} · ei thetag
  • 固定 frame 假設所有層都對齊 global real/imag axes；RPFQ 讓每個 group 學 thetag 與 anchors。
  • W2 時，一個 phase-assignment stage 對應每個原實數權重 1 effective bit；兩個 residual stages形成 2 effective bits。
  • 作者明確把 per-group metadata 與 forward weight-code budget 分開計算。
§3.3 p.5
07 / MAGNITUDE IS NOT FREE

選方向之後，least-squares scale 再對齊 group magnitude

Z-hatg = (alphagCg + betagS(Z-primeg - alphagCg)) ei thetag
  • alpha: 對已選 phase directions 做 least-squares magnitude fitting。
  • beta: 為 residual phase refinement 再給一個 group scale。
  • default S 保留 complex residual 的角度；低複雜度 sign 版本只保留粗 sign。
  • QAT 保留 FP master weights，forward 用 quantized reconstruction + STE。
§3.4 p.5

16 / DEPLOYMENT CAVEAT

2-bit packed weights ≠ all-integer mobile inference

WHAT IS SHOWN

  • ViT-B/16: 338.6 → 47.7 MB (7.1x); Swin-T: 110.2 → 20.4 MB (5.4x).
  • iOS/Android p50 speedups span 1.41x–1.58x.

WHAT REMAINS

  • Activations and surrounding operators run floating point on phone.
  • Backend may unpack or partially convert packed weights.
  • No matched energy measurements.

18 / WHAT THE PAPER ACTUALLY SUPPORTS

把最強證據和外推邊界分開

SUPPORTED

  • 在 ImageNet-1K 三個 ViT-family backbone 的 W2 setting，有完整 main results / ablations。
  • phase metrics、attention perturbation、feature cosine 與 accuracy ranking 一致。
  • native iOS/Android stacks 有 container size 和 end-to-end latency 實測。

NOT YET SHOWN

  • 不是全 graph integer inference，也沒有 A2 stable result。
  • 不是跨資料集、任務、或 robustness/fairness 的廣泛評估。
  • runtime-specific packed-weight behavior與能耗仍未定量。
§4 pp.6-9 · §5 p.9
19 / ENGINEERING TAKEAWAYS

對部署量化，representation design 本身是一個 optimization knob

  1. 若 bottleneck 是極低 bit 的 direction distortion，先換 local coordinate system，未必只靠更複雜 scalar calibration。
  2. 把weight-code bits、metadata、activation precision、runtime packing 分開報，避免把不同成本混成一個 label。
  3. ablation 不只看 Top-1：direction、attention-score 與 feature metrics 能把機制與結果接上。
  4. 手機端要看 end-to-end latency / load time；單一 kernel benchmark 不等於應用收益。
