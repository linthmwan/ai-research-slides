Native and Compact Structured Latents for 3D Generation

Problem

現有 3D latent 的瓶頸不是只有模型大小

  • Field / iso-surface 類方法對 open surfaces、non-manifold geometry、enclosed structures 有內在限制。
  • Unstructured latent 壓縮強，但通常犧牲 reconstruction fidelity。
  • Shape then multiview texture 會帶來 view inconsistency、baking/post-processing 成本與幾何-材質錯位。
  • TRELLIS 的 SLAT 已經很接近，但仍依賴 multiview 2D features / rendering supervision，不是直接從 native 3D asset 學 latent。
這篇的核心賭注：表示法先對，generator 才真的能 scale。

O-Voxel

O-Voxel：一個 active voxel 同時放 shape tuple 與 material tuple

f = {(fshapei, fmati, pi)}Li=1
  • 只存 intersecting asset 的 active voxels，空格不進 latent。
  • shape tuple：dual vertex、edge intersection flags、quad splitting weights。
  • material tuple：base color、metallic、roughness、opacity。
§3.1 p.3-4; Figure 3 p.3
Shape mechanism

Flexible Dual Grid：不用 SDF，直接從 mesh intersection 解 dual vertices

  • 每個 primal cell 對應一個 dual vertex；每條 primal edge 對應 dual face，連接相鄰 dual vertices。
  • mesh→O-Voxel：偵測 mesh-surface edge intersections，直接得到 intersection flags 與 Hermite data。
  • O-Voxel→mesh：跨 intersected edge 連 dual vertices，quad 可依 splitting weights 分成 triangles。
  • 作者強調不需要 SDF evaluation、flood-fill 或 iterative optimization。
e(v)=Σd²plane + λboundΣd²edge + λregd²qbar
boundary-edge term 是 open surfaces 對齊的關鍵；regularization 則避免 QEF singularity。
§3.1.1 p.4
Material mechanism

材質不是後貼 2D texture，而是 sparse voxel 上的 volumetric PBR attributes

  • 每個 active voxel 存 `c,m,r,α`：base color RGB、metallic、roughness、opacity。
  • Texture→O-Voxel：project voxel center 到 intersecting triangles，按 UV + mip level 取樣，再 weighted-average。
  • O-Voxel→Texture：在 mesh vertex 或 texture texel 查詢點做 trilinear interpolation。
Base ColorMetallicRoughnessOpacity

Opacity 讓 translucent / glass-like assets 進入表示法；這是許多前作沒有的材料能力。

§3.1.2 p.4; Algorithm 3-4 p.14-15
Compression

SC-VAE：把 O-Voxel 壓到 generator 可以負擔的 token 數

這裡不是把 Transformer 硬塞進 sparse grid；作者選 fully sparse-convolutional VAE，目標是高解析下的效率與跨解析泛化。
§3.2.1 p.5; Appendix Table 4 p.15
SC-VAE internals

Sparse residual autoencoding：把 space 資訊搬到 channel，再搬回來

Down: Frawcoarse = stack(Fchild1,...,Fchild8) → avg_groups
Up: Frawfine = unstack(Fcoarse) → dup_groups
  • downsampling factor 2 時，把 8 個 child voxels aggregate 到 channel dimension。
  • upsampling 時做對稱 channel-to-space shortcut。
  • inactive nodes 由 early-pruning mask 跳過，降低 runtime / memory。
  • optimized residual block 用 point-wise MLP 取代第二個 sparse conv，改善高 sparsity 下的效率/品質。
§3.2.1 p.5
Training objective

兩階段 VAE training：先穩定 latent，再加 render-space perceptual loss

  1. Stage 1：256³ direct O-Voxel regression；shape 用 MSE/BCE，material 用 L1，另有 KL loss。
  2. Stage 2：提升到 512³，加 mask/depth/normal/material render loss；normal/material 用 L1 + SSIM + LPIPS。
  3. shape VAE 與 material VAE decoupled；material generation 可以在既有 shape 上單獨執行。
Ls2 = Ls1 + Lrender; dp(a,b)=||a-b||1 + 0.2·SSIM + 0.2·LPIPS
§3.2.2 p.5; Appendix A.3 p.14
Generator

三個 sparse DiT：structure → geometry → material

  1. Sparse structure generation：先預測 sparse voxel occupancy layout。
  2. Geometry latent generation：在 active voxels 裡生成 geometry latents。
  3. Material latent generation：condition on image + generated geometry，生成 PBR material latents。
1.3B x 3width 153630 blocks12 heads

DINOv3-L 提供 image conditioning；DiT 採 AdaLN-single + RoPE。

§3.3 p.6; §4 p.6; Appendix Table 5 p.15
Flow matching

生成訓練採 rectified / conditional flow matching

x(t) = (1-t)x0 + tε
LCFM(θ)=Et,x0,ε ||vθ(x(t),t) - (ε-x0)||²
  • forward path 是 data sample 到 random noise 的線性插值。
  • network 學 time-dependent vector field，把 noise distribution 導回 data distribution。
  • 延續 TRELLIS 策略，採 logitNorm(1,1) timestep sampling 以提升 generation quality。

Scaling / systems

compact latent 讓 test-time compute 與 resolution 可以分開調

  • 1024³ O-Voxel 可 downsample 成更高解析 sparse structure layout，再重跑 geometry stage 到 1536³。
  • 在同一 training resolution 內，也可先生成 O-Voxel 再 downsample layout，修正 local errors 並提高清潔度。
  • FlexGEMM 用 Triton masked implicit GEMM、Gray-code grouping、Split-K，對 sparse conv benchmark up to 2x speedup。
§4.5 p.8-9; Appendix B p.16
Failure boundary

作者自承限制：voxel 尺度仍然是邊界

  • Aliasing: 比 voxel size 更細的 geometry 會被平均；非常接近的平行面若落在同一 voxel，QEF 可能把 vertex 放到兩者中間。
  • Material blur: 同一 voxel 內多個表面的 PBR attributes 會被 volumetric average。
  • Small holes: sparse decoder 偶爾無法保證 perfectly closed manifold surface，需要 hole filling 等後處理。
  • No semantics yet: O-Voxel 目前沒有 part-level segmentation 或 graph topology。
所以它不是消滅 3D representation 問題，而是把瓶頸從 view-dependent postprocessing 移到可被分析的 voxel-resolution/decoder stability 問題。
Limitations p.20
Engineering interpretation

對 AI image / 3D 工程的啟發

  1. Representation first: 如果下游要 editable / relightable asset，latent 必須存 PBR/material primitives，不要只靠 rendered RGB supervision。
  2. Compression must be audited: token 數少不是勝利；要用 all-surface MD、normal PSNR、material render metrics 檢查內部結構與材質。
  3. Generator simplicity is a downstream effect: O-Voxel + SC-VAE 壓縮夠好，才讓 vanilla sparse DiT 成立。
  4. Failure cases are geometric: 小 holes、近距雙面、sub-voxel 細節是部署時該優先做 QA 的地方。
Derived from §3-4 and Limitations p.20
