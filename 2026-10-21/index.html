TL;DR

Pyramid Flow 把跨解析度「生成 + 解壓」寫成同一條 flow。

空間上：早期 noisy step 留在低解析度。時間上：遠端 history 留在低解析度。單一 DiT 用 unified objective 共同學習。

關鍵不是多階段 pipeline；是機率路徑在跨尺度跳點仍保持連續。
Abstract p.1 · §1 pp.1–2 · §3.2–3.3 pp.4–6
PROBLEM · SPATIOTEMPORAL COST

為什麼影片模型特別吃算力？

  • VAE 已壓縮像素，但高解析長影片仍有巨大 token 數。
  • full-sequence diffusion 在每個 denoising timestep 都處理 full-resolution latent。
  • autoregressive 規模化雖可生成更長影片，full-resolution history condition 仍把 memory / compute 拉高。
119,040 tokens<=15,360 tokens

例：10s、241-frame 影片；後者是論文的 pyramid token 上限。

§1 p.2 · §3.3 p.5
PRIOR APPROACH

Cascade 省算力，但把知識切成孤島。

  • 主流作法：先低解析度生成，再交給獨立 super-resolution model。
  • 每個 sub-stage 分別最佳化：generation 與 upsampling 的表徵 / 知識不容易共用。
  • Pyramid Flow 的目標是保留 multi-scale 的成本優勢，卻把所有 stage 放入單一可端到端訓練的 DiT。
問題不是「要不要金字塔」；而是「金字塔 stage 是否仍在同一條生成路徑上」。
Abstract p.1 · §1 pp.1–2 · §3.2.1 p.4
INTUITION

早期噪聲沒有必要用 full resolution 處理。

作者的觀察：初期 latent 極 noisy、資訊低。先在壓縮 latent 演進，末段才補 full-resolution detail。

Fig.1 / §1 p.2
PRELIMINARY · FLOW MATCHING

Flow matching 學的是把 noise 推向 data 的 velocity field。

d xt / d t = vt(xt)
  • 用 conditional probability path 定義 supervision，而不是逐步模擬 diffusion。
  • 標準線性 path 是 xt = t x1 + (1 - t) x0。
  • 這個彈性讓作者能把 path 的兩端改成不同解析度的 latent。
§3.1 p.3 · Eq.1–4
METHOD · SPATIAL PYRAMID

一條 path，分 K 個跨解析度 windows。

只在最末 stage 做 full resolution；均勻 stage partition 下，spatial cost 近似縮為 1 / K。
Fig.2 · §3.2 p.4 · Eq.5–6
METHOD · UNIFIED TRAINING

同一個 target 同時教會「生成」和「解壓」。

  • 每個 stage 的 start / end 同時調整 resolution 與 noise level。
  • 兩端共享同一個 noise direction：避免 random coupling 造成多條 flow trajectory 互相交叉。
  • 模型回歸 endpoint difference；全部 stage 由單一 DiT 端到端共同最佳化。
target = x_hate,k - x_hats,k
§3.2.1 p.4 · Eq.7–11 · Appendix C.4 pp.22–23
METHOD · JUMP CORRECTION

為什麼跳到更高解析度時必須 renoise？

  • 直接 upsample 會改變 latent covariance：鄰近位置變得過度相關。
  • rescaling 先對齊 mean，corrective Gaussian noise 再對齊 covariance。
  • nearest-neighbor case 取 gamma = -1/3 以降低 block 內相關性，且保持 covariance 半正定。
Renoising 不是為了「再加一點噪聲」；它是跨解析度 transition 的 distribution matching。
§3.2.2 p.5 · Eq.12–15 · Appendix A pp.16–17
METHOD · TEMPORAL PYRAMID

遠端 history 可低解析度；近端 history 保留細節。

訓練時對 history 加小噪聲緩解 autoregressive error accumulation；推論使用 clean generated history。

Fig.3 · §3.3 p.6 · Eq.16–17
METHOD · TOKEN ECONOMICS

壓縮的是舊 history 的解析度，不是影片長度。

  • 若 T 個 history latents、K 個低解析度，作者表示多數 frames 在 1 / 2K resolution。
  • token 數最多可降為 1 / 4K；訓練效率的推導上限為 16K / T。
  • 實作仍可用 full-sequence attention，因為輸入 token 已被 representation 壓低。
這把「長 context」的問題，轉成「哪些時間位置值得高解析度」的配置問題。
§3.3–3.4 p.6
IMPLEMENTATION

保持標準 Transformer pipeline，而非另造專用架構。

  • Base model：2B MM-DiT，3D VAE 壓縮比 8 x 8 x 8，實驗固定 3 個 pyramid stages。
  • blockwise causal attention 阻止 token 看未來 frame；spatial position encoding 外插、temporal input 內插。
  • 不同 token count 的 samples 以 length-balanced packing 組 batch；同一 autoregressive formulation 可同時學 image / video。
§3.4 p.6 · §4.1 p.7
EXPERIMENTAL SETUP

公開資料、2B model、10M 級影片語料。

  • 影片資料含 WebVid-10M、OpenVid-1M、Open-Sora Plan 的高解析無水印影片；postprocess 後約 10M single-shot videos。
  • VBench：16 個細粒度維度；EvalCrafter：約 17 個 objective metrics。
  • 最終模型支援 5–10s、768p、24 fps；三段訓練的高解析 stage 為 50k steps。
Abstract p.1 · §4.1 p.7 · Appendix B p.17
EFFICIENCY

20.7k A100 GPU hours：訓練 10s / 241-frame 模型。

  • 論文報告：full-sequence diffusion 的 input token 為 T N；Pyramid Flow 約為 T N / 4K。
  • 相應的 attention-style compute 項由 T2N2 變為 T2N2 / 16K。
  • 5s / 384p clip 的推論約 56 秒；作者明說仍只是與 full-sequence counterparts 相當，非 real-time。

MECHANISM · THE CROWN PAGE

把 expensive compute 留給「已經有內容」的末段。

Spatial pyramid 把 early noisy denoising 壓縮；temporal pyramid 把遠端 history 壓縮。Unified flow 與 renoise 再保證這不是斷開的 cascade。

收益的因果鏈：token budget 降低 → 同資源可容納更多 samples / 更快收斂 → motion-quality 的可見改善。
§1 p.2 · §3.2–3.3 pp.4–6 · §4.4 p.10
ABLATION · SPATIAL PYRAMID

同等資源下，pyramid flow 幾乎 3x 更快收斂。

比較控制 data、batch token、hyperparameters、architecture；圖表未給可安全轉錄的逐點 FID，因此只陳述作者的「almost three times」結論。

Fig.7 / §4.4 p.10
ABLATION · TEMPORAL PYRAMID

同訓練 steps，full-sequence baseline 還沒有收斂。

作者報告 full-sequence variant 出現 fragmented visual details 與 incoherent motion；pyramid variant 有較佳 temporal consistency。

Fig.8 / §4.4 p.10
ABLATION · RENOISING

拿掉 corrective noise：全局形狀還在，細節卻被 block artifacts 吃掉。

這支持 renoising 的定位：它修正 upsample jump 的 correlation mismatch，而不是可有可無的 sampling trick。
Fig.10 · Appendix C.2 p.21
ABLATION · CAUSAL ATTENTION

雙向 attention 的「資訊更多」直覺，在 autoregressive video 反而不穩。

  • bidirectional variant 的 subject shape / color 隨 generation 持續改變。
  • 作者推論：ongoing generation 回頭影響 history condition，使條件本身偏移。
  • causal attention 固定 history 作為 predetermined condition，穩住長程生成。
Fig.11 · Appendix C.2 p.21
ANALYSIS · COUPLED NOISE

共享 noise direction，讓 flow trajectory 少交叉、較直。

獨立端點取樣使方向隨機而容易交叉；coupled endpoints 形成較組織化、可能平行的 path。

Fig.13 · Appendix C.4 pp.22–23
LIMITATIONS

效率不是免費的：temporal compression 會留下可追的代價。

  • 只支援 autoregressive generation，不能直接處理 keyframe / video interpolation。
  • 長時間可能出現 subtle subject inconsistency；face consistency 也被作者點名為 temporal history compression 的弱點。
  • 尚非 real-time inference；沒有 prompt rewriting，且資料過濾使 scene transitions 未被充分學習。
Limitations p.23 · Appendix C.1 p.20
ENGINEERING TAKEAWAY

對實作團隊的三個可移植問題。

  1. 能否把不同解析度的任務寫成同一個 continuous target，而非各自訓練的 cascade？
  2. 長 context 裡，哪些 token 只需要 semantic / layout information，哪些才需要 full-detail condition？
  3. 跨表示跳轉時，是否有明確的 distribution mismatch 要修正，而不是把 artifact 歸咎於 sampler？
Pyramid Flow 的價值是給出一個可檢驗答案：representation allocation + path continuity 必須一起設計。
§3.2–3.4 pp.4–6 · Appendix C.2 pp.20–21
