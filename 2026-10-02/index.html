MixLLM: LLM Quantization with Global Mixed-precision between Output-features and Highly-efficient System Design

用全模型 loss 找出值得保留位元的 output channels，再把這個演算法選擇變成能跑滿 GPU 的 kernel。

Zhen Zheng · Xiaonan Song · Chuanjie Liu · Microsoft

TL;DR

MixLLM 的關鍵不是「混幾種 bit」，而是把有限的 8-bit 預算放到跨層最會影響 final loss 的 output channels。

W4.4A8 = 90% W4 + 10% W8 + A8；結構化 channel split 讓 accuracy、memory、kernel efficiency 可一起最佳化。
Abstract p.1 · §3.1.1 p.4
Problem · quantization triangle

量化的三角形：accuracy、memory、execution efficiency

  • Weight-only 壓參數記憶體，但大型 batch 時 dequantization 會拖累 compute-bound MatMul。
  • Weight-activation 可吃到低位元 compute，但 activation 更難量化，而且新增 dequantization 工作。
  • FP16 outlier separation 雖保 accuracy，卻轉成不規則 sparse workload；本文引述 sparse MatMul 利用率可低於 10%，dense 可超過 60%。
真正的目標不是最小 bit-width；是部署情境下的 Pareto point。
§1 pp.1-2 · §2.1 p.3
Why output features?

把 mixed precision 切在 output channel，先讓系統問題有解

INPUT-FEATURE SPLIT

  • 跨 feature 累積到同一 output，工作彼此耦合。
  • 系統與 kernel 排程較難切乾淨。

OUTPUT-FEATURE SPLIT

  • 不同 output channels 是 disjoint MatMul subproblems。
  • 4-bit / 8-bit 子問題可並行，最後 fused epilogue scatter 回原 index。
演算法的 granular choice 同時決定了 kernel 能不能規整化。
§3.1.1 p.4 · §3.4 p.7
Contributions

從 global selection 到 GPU kernel 的一條鏈

  1. 跨所有 linear layers 排序 output-channel salience。
  2. 用 Taylor / empirical Fisher 近似 quantization 對 final loss 的影響。
  3. W4A8 two-step dequantization，保住 INT8 Tensor Core。
  4. 以 pipeline 與 quantization-aware Roofline 連接 accuracy choice 和真實吞吐。

Quantization decision

W4.4A8 的 sweet spot：W4/W8 mix，activation 保持 A8

ACCURACY

  • A4 會帶來顯著 accuracy drop。
  • 4-bit weight 採 asymmetric；8-bit tensor 採 symmetric。
  • weight/activation 都 group-wise，group size = 128。

SYSTEM

  • weight tensor 較大，壓 A8 到 A4 未必帶來顯著 efficiency。
  • W4.4A8 以 10% 8-bit output features 補最敏感通道。
§3.1.2 p.4 · §4.1 p.7
Global salience

每個 channel 問的不是 local error，而是 final loss 差多少

Sc = | l(cq) - l(c0) |
  • 以 channel 被量化前後的 loss distance 排序。
  • Taylor expansion 以 empirical Fisher 近似 Hessian。
  • 保留 first-order 與 second-order contribution；不是只取 diagonal/local proxy。
Eq.1-4 · §3.2 pp.4-5
Global precision search

一個 total budget T，跨 layer 挑 top-T output channels

OFFLINE SEARCH

  1. 量化每層候選 weight。
  2. 計算每個 output channel 的 salience。
  3. 把所有 layer/channel tuple 集成全域表。
  4. 按 salience 由高到低排序。

ALLOCATION

  • 前 T 個配高 precision（本文 default 8-bit）。
  • 其餘配低 precision（本文 default 4-bit）。
  • 因此每一層的 8-bit 比例自然不同。

Kernel design

W4A8 不先還原成 FP16；分兩步留在 INT8 Tensor Core path

Y = ((Wq - z) x Aq) x sw x sa
  1. 先 partial-dequant：由 Wq 扣 zero-point。
  2. 以 INT8 Tensor Core 做 MatMul。
  3. 在 group 結尾套用 weight / activation scales。
把 asymmetric W4 的 zero-point 處理移進可控的 integer path。
§3.3 p.5 · §3.5 p.7
Fast I2F

把昂貴 integer-to-float conversion 變成 add/subtract

  • 利用一段 binary range 內 int32 與 float32 的位元對應；加 bias 後 reinterpret，再以 float bias 還原。
  • group size 128 落在作者給出的安全範圍。
  • 作者在 A100、M/N/K = 512/4096/4096 的量化 MatMul 報告超過 20 TOPS 改善。
system co-design 的價值：小小的 cast overhead 會在 group-wise W4A8 變成 ceiling。
§3.3 pp.5-6
Runtime pipeline

兩個 buffer、預先排好 weight layout，讓三種工作重疊

WITHIN A GROUP

  • register-level group buffer 做 per-group accumulation。
  • 預先載入 bias；group end 再扣 float bias、套 scales。
  • vsub4 一條 instruction 做四個 int8 subtract。

END-TO-END

  • ahead-of-time prepack weight，避免 runtime permutation。
  • overlap global-memory load、SIMT dequant、Tensor Core MatMul。
  • 4-bit / 8-bit 子問題用 CUDA Graph 並行。
§3.3 pp.6-7 · §3.4 p.7
Quantization-aware Roofline

W4A8 讓 memory-bound slope 上移，卻多了一個 SIMT ceiling

MEMORY

  • G=128 時 W4A8 effective weight footprint = 0.5 + 2.5/G bytes。
  • 比 W8A8 更少的 weight traffic 對小 batch decoding 有利。

COMPUTE

  • W4 unpack + zero-point subtraction 必須持續餵給 Tensor Cores。
  • SIMT pre-GEMM work 形成比 absolute INT8 peak 更低的 ceiling，因此更早進 compute-bound。
§3.5 p.7
Evaluation protocol

不只測 PPL：模型家族、downstream tasks、A100/H100 kernel 都覆蓋

  • Models: Llama 3.1/3.2、Qwen2.5、Mistral；baselines 包含 SmoothQuant、QuaRot、QServe。
  • PPL: WikiText2 / C4；downstream: BBH、GPQA、MMLU-Pro、MuSR、ARCc、HellaSwag。
  • MixLLM salience calibration：WikiText2 128 samples，sequence length 2048；A100 80GB / CUDA 12.1，另測 H100。

Ablation

accuracy 是累積結果：global allocation 不是唯一一個 knob

  1. 從 W4A4 RTN per-channel/token symmetric 起步。
  2. 加 A8、asymmetric W4、group-wise weight/activation 後，PPL 明顯下降。
  3. 再加 10% high-precision outputs、blocked Fisher + first-order term。
  4. 最後 GPTQ、group reorder、clipping 使 Llama 3.1 8B WikiText2 PPL 收至 6.420。
selection、quantizer、kernel-friendly layout 是互補，不該當成單一 trick 解讀。

Robustness checks

salience search 不需很大的 calibration set，也可與 KV quantization 疊加

CALIBRATION

  • Llama 3.1 8B: 128、64、32、16 samples 都是 PPL 6.42。
  • Qwen2.5 7B: 128-32 samples 6.92；16 samples 6.93。
  • 用 C4 搜 salience、WikiText2 測 PPL，兩個模型結果相同。

KV QUANT

  • W4.4A8 + KV8：Llama 3.1 8B PPL 6.42，與不量化 KV 相同。
  • Qwen2.5 7B：6.92 → 6.96。
  • KV quantization 與 weight-activation quantization 是 orthogonal。

Engineering takeaways

若 accuracy 最敏感的部分有結構化的軸，就不要把它做成 sparse exception；把它變成可獨立排程的 dense subproblem。

先選 tensor axis，再選 salience objective，最後才寫 kernel；順序反過來通常只能得到其中一個局部最優。

Why output features are a system choice

the mixed-precision between output features makes the system design easier than between input features because the calculation of different output features are disjoint sub-problems.
