PixelDiT: Pixel Diffusion Transformers for Image Generation

Yongsheng Yu, Wei Xiong, Weili Nie, Yichen Sheng, Shiqiu Liu, Jiebo Luo · NVIDIA / University of Rochester
CVPR 2026 Main ConferencearXiv:2511.20645v2Pixel-space diffusion

A single-stage DiT trained directly in pixel space: no VAE, no latent bottleneck, but still efficient through a dual-level transformer.

TL;DR

PixelDiT makes pixel-space diffusion practical by compressing only the attention path, not the image representation.

Patch-level DiT learns global semantics; a thin pixel-level PiT refines texture with pixel-wise AdaLN and token compaction.
Abstract p.1; §1 pp.2-3; §3.2 p.5
Problem

Latent diffusion is efficient, but the VAE is a lossy side-channel

  • Separate objective: the autoencoder is trained for reconstruction, not for the downstream generative objective.
  • High-frequency loss: fine text, texture and boundaries can be removed before diffusion ever starts.
  • Editing failure mode: VAE reconstruction distortion can accumulate during FlowEdit-style local edits.
The paper’s bet: if pixel modeling is structured correctly, direct pixel denoising can keep details without becoming computationally impossible.
§1 p.2; Fig.1b p.1
Why prior pixel diffusion was stuck

Pixel-space models face a semantics-vs-texture cost trap

Over-patchify

  • Shorter sequence length
  • Cheaper global attention
  • But weak dense pixel modeling and blurred fine content

Near-pixel granularity

  • Better per-pixel interactions
  • Preserves local texture
  • But H×W attention is quadratic and too expensive
PixelDiT does not choose one side; it splits the job into two pathways.
§1 p.2
Core architecture

Dual-level DiT: patch pathway for semantics, pixel pathway for texture

  • Patch-level branch uses 16×16 patch tokens for long-range layout and content.
  • Pixel-level branch keeps one token per pixel but uses small Dpix=16 and shallow depth M=4 in XL.
  • Semantic tokens condition the pixel stream as scond = sN + t.
§3.1 pp.3-4; Tab.3 p.6
Mechanism 1

Pixel-wise AdaLN gives every pixel its own semantic modulation

Θ = Φ(scond) ∈ R(B·L)×p²×6Dpix
  • Patch-wise AdaLN repeats one modulation vector across all pixels in a patch.
  • Pixel-wise AdaLN expands each semantic token into p2 separate scale, shift and gate sets.
  • This makes dense local updates aware of global semantic context.
§3.2 p.4; Fig.3 p.4
Mechanism 2 · Crown page

Pixel Token Compaction is the trick: compress-attend-expand, then return to pixels.

Sequence length drops from H×W to L=(H/p)×(W/p). With p=16, that is a 256x shorter attention sequence; attention cost drops approximately by p4.
§3.2 p.5; §4.5.2 p.9
Why this is not just another bottleneck

The compression is temporary and local to attention

  1. Embed: image pixels become per-pixel tokens.
  2. Compact: p2 pixel tokens inside each patch are linearly compressed for global attention.
  3. Attend: attention runs on compact patch-length sequences.
  4. Expand: attended representation expands back to pixel tokens; residual paths keep high-frequency detail alive.
A VAE permanently maps the image through a lossy latent representation; PTC is an internal compute shortcut.
§3.2 p.5
Text-to-image extension

Text is fused at the patch level; pixel pathway stays unchanged

  • Gemma-2 provides text embeddings; MM-DiT fuses text and image tokens in the patch pathway.
  • Pixel pathway receives text intent indirectly through semantic tokens, not direct text tokens.
  • T2I configuration: 1.3B params, N=14, M=2, D=1536, Dpix=16.
§3.3 pp.5-6; Fig.7 p.13; Tab.8 p.12
Training recipe

Velocity matching in pixel space, plus REPA as semantic regularizer

Ldiff = E[||fθ(xt, t, y) - vt||²]
  • Rectified Flow objective trains the model to predict velocity directly in pixel space.
  • REPA aligns mid-level patch tokens with frozen DINOv2 features.
  • Ablation shows REPA is not optional for fast convergence.
§3.4 p.5; §C.2 p.14; Tab.11 p.14

Text-to-image

Mechanism proof

Without compaction: 82,247 GFLOPs + OOM. With PixelDiT: 311 GFLOPs + 1.61 FID.

The ablation isolates why the model works: compact global attention is necessary, but pixel-pathway attention still matters for quality.

Ablation · REPA / depth / compaction rate

Three engineering lessons from the appendix

  1. REPA matters: removing it worsens 80-epoch FID from 2.36 to 6.58; 160-epoch FID from 1.97 to 4.33.
  2. Pixel pathway depth matters: N=26, M=4 gives the best convergence-quality trade-off under ~30 layers.
  3. More compact can be better: Seq Len L (1x) beats 2L/4L around 300K and reaches 1.94 at 1M.
Tab.11 p.14; Fig.10 p.15; §C.3 pp.15-16

Limitations

What the paper does not make disappear

  • Pixel-space data and noise distributions are still more complex than latent-space ones.
  • The recipe relies on architecture, objective, scheduler and optimization choices; not just “remove VAE”.
  • At p=16, GFLOPs rise from 311.19 at 256² to 1,352.24 at 512² and 7,147.17 at 1024².
  • At 1024 T2I, throughput 0.33 samples/s is competitive but below FLUX-schnell 0.5 samples/s.
§5 p.10; Tab.16 p.17; Tab.4 p.7
Image generation engineer takeaways

Where this changes design intuition

  • VAE-free generation is not enough: the decisive question is how pixel interactions are modeled.
  • Compress for compute, not for storage: temporary token compaction avoids the semantic loss of an autoencoder bottleneck.
  • Semantic conditioning can be sparse-to-dense: text/global layout can live in patch tokens while pixel tokens receive per-pixel modulation.
  • Editing is the practical stress test: preservation of unedited regions is where pixel-space models show the clearest advantage.
Synthesis from §3.1-§4.5; all claims cited in prior slides
Appendix · Highlight 1

PixelDiT is an explicit pixel-modeling structure, not a naive return to pixels

To address these challenges, we propose PixelDiT, a single-stage, fully transformer-based diffusion model that performs end-to-end training and sampling in pixel space while explicitly structuring pixel modeling.

PixelDiT 的核心不是單純把 latent diffusion 搬回 pixel space，而是把 pixel modeling 的結構先拆開，讓端到端訓練可行。§1 p.2

Appendix · Highlight 2

The compaction lever is sequence length

This reduces the attention sequence length from H×W to L=(H/p)(W/p), a p²-fold reduction; with p=16, this yields a 256× shrinkage.

關鍵效率槓桿是 sequence length shrink，而不是少做 pixel update；注意 attention cost 又會近似帶來 p⁴ 級收益。§3.2 p.5; §4.5.2 p.9

Appendix · Highlight 3

Patch-only learning is not enough for fine detail

Without pixel modeling, i.e., the visual content is only learned at the patch level, it will be challenging for the model to learn the fine details, and the visual quality will degrade significantly.

ablation 把主張釘死：只有 patch-level semantics 不夠，pixel-level pathway 才是保細節的必要條件。§4.5.1 p.9
